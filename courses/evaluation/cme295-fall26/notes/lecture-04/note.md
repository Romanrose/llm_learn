# CME 295 Lecture 4：Reinforcement Learning with LLMs 课程笔记

## 学习目标

本讲聚焦 LLM 后训练（post-training）中的强化学习方法，承接上一讲的预训练、监督微调（SFT）与偏好调优（preference tuning）框架。学完后应能：

1. 说清 RL 基本要素（agent、state、action、policy、reward）如何映射到 LLM 的 token 生成与补全生成；
2. 区分两大类奖励来源：基于人类偏好的 RLHF 与基于可验证奖励的 RLVR；
3. 从第一性原理推导策略梯度中的 log-derivative trick，理解它的直觉含义；
4. 解释 PPO 与 GRPO 各自如何应对 RL 训练的三个核心挑战，并说清二者结构差异；
5. 说明 on-policy distillation 的动机、反向 KL 的作用，以及它的适用条件与局限。

---

## 课程主线

上一讲留下两个未展开的阶段：**偏好调优**与**推理能力提升**，二者都依赖 RL 技术，但当时没有给出损失公式。本讲的任务就是补上这部分：先建立 RL 与 LLM 的映射，再定义奖励，再推导目标函数的梯度，然后依次剖析 PPO、GRPO，最后介绍一种不依赖奖励模型的替代路线——on-policy distillation。

课程反复强调的教学立场是：RL 论文数学量大、记号约定不统一，应优先抓住直觉，再回到公式。讲义特别提醒三处记号陷阱：

- **R** 有时表示 reward，有时表示 ratio（概率之比）；本课用 $\rho$ 表示后者；
- **policy** 有当前策略 $\pi_\theta$、旧策略 $\pi_{\text{old}}$、参考策略 $\pi_{\text{ref}}$ 之分，论文中常混用；
- **L** 在监督学习中是待最小化的损失，而在 RL 中常指待**最大化**的目标函数；读 PPO 论文时要先确认方向。

## 核心概念

### 1. RL 与 LLM 的映射

标准 RL 中，agent 在环境状态 $s$ 下依策略 $\pi_\theta$ 选择动作 $a$，获得奖励，目标是最大化累计奖励。映射到 LLM：

- **agent** = LLM；
- **state** = 输入（提示或已生成的前缀）；
- **action** = 下一个 token，或整体上视为一个完整响应；
- **policy** $\pi_\theta$ = 模型在给定输入下输出 token / 响应的概率分布。

讲义指出，token 级奖励难以定义，因此实践中奖励通常定义在**补全（completion）层面**：输入是 prompt，动作是 response，$\pi_\theta$ 是给定 prompt 生成该 response 的概率。

### 2. 两类奖励来源

- **无绝对真值、偏主观**：用人类偏好建模，通过 Bradley–Terry 公式训练奖励模型，此类方法称 **RLHF**。关键工程点：奖励模型事先用人类偏好训练好，训练循环中不再让人参与，只调用冻结的奖励模型打分。
- **可验证正确性**：数学题有标准解、代码可通过测试用例，存在确定性判定方式，此类方法称 **RLVR**（reinforcement learning with verifiable rewards），常见于推理任务。

### 3. 策略梯度与 log-derivative trick

目标为最大化从当前策略采样轨迹时的期望奖励：

$$J(\theta) = \mathbb{E}_{\tau \sim \pi_\theta}[R(\tau)] = \int R(\tau)\,\pi_\theta(\tau)\,d\tau$$

对 $\theta$ 求梯度时，只有 $\pi_\theta$ 依赖 $\theta$，$R$ 是冻结的。利用恒等式

$$\nabla_\theta \pi_\theta(\tau) = \pi_\theta(\tau)\,\nabla_\theta \log \pi_\theta(\tau)$$

得到

$$\nabla_\theta J(\theta) = \mathbb{E}_{\tau \sim \pi_\theta}\left[R(\tau)\,\nabla_\theta \log \pi_\theta(\tau)\right]$$

**直觉（课程原意）**：正奖励会激励模型提高该类动作的概率，负奖励会激励模型降低其概率。由于是最大化目标，更新为梯度**上升**：$\theta \leftarrow \theta + \alpha \nabla_\theta J$。

**on-policy 的代价**：该期望要求轨迹由**当前**策略采样，因此每次更新都要让模型逐 token 生成响应，无法并行，非常昂贵。与之对比，给定完整响应后计算其概率是并行的、廉价的——这正是后续重要性采样技巧的着眼点。

### 4. 重要性采样比

引入一个固定参数的策略 $\pi_{\theta_{\text{fixed}}}$，把期望改写为：

$$\mathbb{E}_{\tau \sim \pi_\theta}[R(\tau)] = \mathbb{E}_{\tau \sim \pi_{\theta_{\text{fixed}}}}\left[\frac{\pi_\theta(\tau)}{\pi_{\theta_{\text{fixed}}}(\tau)} R(\tau)\right]$$

比值 $\frac{\pi_\theta}{\pi_{\text{old}}}$ 称为 **importance sampling ratio**。工程意义：用一批 rollout 做多次更新，采样一次、复用多次；但需用该比值修正“数据来自旧策略”这一事实。

### 5. RL 训练的三大挑战（本讲的组织骨架）

1. **梯度方差高**：若奖励缺少基线（baseline）参照，绝对数值大小会带来大幅噪声更新。例：好答案 101、坏答案 100，二者都很大，更新幅度都很大，只是相对略小；理想做法是相对“该状态的期望奖励”比较。
2. **缺少 token 级信用分配**：补全级奖励无法区分“答案对但中间步骤错”的情况。讲义举例：Teddy 在密封盒中、盒子被搬到厨房，模型答“Teddy 从盒子里爬出来，走到厨房，答案是厨房”——最终答案正确，但“走路”这一步是错的，而补全级奖励会一并激励所有 token。
3. **缺少对策略漂移的约束**：起始策略已经过预训练与 SFT，本身不错；奖励模型又可能不完美（讲义用“靠掌声强度优化讲课”比喻 reward hacking）。因此需要约束新策略不要离起点太远，也避免在前序任务上能力回退。

### 6. PPO：优势 + 裁剪 + KL

**价值函数与优势**。为解决问题 1 和 2，引入 token 级价值函数 $V$：给定输入与部分补全，若继续从当前策略采样解码，期望的最终奖励是多少。它定义的基线使每个 token 的贡献可以被定位。最朴素的优势估计是相邻价值的差：

$$A_t \approx V(\text{到该 token}) - V(\text{到前一 token})$$

讲义明确说明实际更复杂（一个 token 既可能直接提高高奖励的概率，也可能把模型置于更有利的后续位置），并点名 **GAE（generalized advantage estimation）** 处理后者，但声明 GAE 不在本课考试范围内。价值函数与策略联合训练（共享 backbone，损失包含价值损失与策略损失），必须保持同步，因为价值的定义依赖“当前策略”。

**目标函数**。用重要性采样比修正旧策略数据：

$$\mathbb{E}\left[\rho_t A_t\right],\quad \rho_t = \frac{\pi_\theta}{\pi_{\text{old}}}$$

**裁剪（clipping）**。若不处理，只要 $A>0$，梯度就始终激励增大 $\rho$，策略会越走越远。裁剪在 $\rho$ 偏离 1 过远时制造零梯度区域，消除继续增大该动作概率的激励；$A<0$ 时对称地消除继续压低概率的激励。这就是 PPO 中 “P”（proximal）的来源。

**KL 惩罚**。另一种约束方式是 KL 散度：$D_{KL}(P\|Q) = \mathbb{E}[\log(P_i/Q_i)]$。通常惩罚当前策略相对**参考策略** $\pi_{\text{ref}}$（SFT 或基础模型，全程冻结）的偏离。注意区分三个策略：$\pi_\theta$ 当前更新；$\pi_{\text{old}}$ 生成该批数据的策略；$\pi_{\text{ref}}$ 固定基准。讲义明确：实践中常同时施加两种约束——相对旧策略的比值裁剪（迭代约束）与相对参考策略的 KL（绝对约束）。

**与 DPO 的联系**。讲义回顾 DPO 损失形如 $-\log\sigma(R_W - R_L)$，其中奖励被参数化为 $\beta \log \frac{\pi}{\pi_{\text{ref}}}$，并指出此处的 $\beta$ 与 KL 惩罚中的 $\beta$ 是同一个：$\beta$ 越大，偏离参考策略的代价越高，sigmoid 越早饱和，偏离的激励越小。

**读 PPO 论文的两个提醒**：其中的 L 是待最大化的目标函数而非损失；其中的 R 是 ratio 而非 reward。

### 7. GRPO：去掉价值函数

PPO 的主要麻烦是要额外训练价值模型并维持同步。**GRPO（group relative policy optimization）** 的核心卖点是**不需要价值函数**。做法是：对同一 prompt 用正温度采样 $G$ 个响应，分别打分，然后用组内统计量构造优势：

$$A_i = \frac{r_i - \text{mean}(r)}{\text{std}(r)}$$

即用“相对同组其他响应表现如何”替代价值函数提供的基线，同时天然获得补全级的信用信号。约束机制沿用同一套：比值裁剪 + KL 惩罚。所需模型只剩策略模型、奖励模型（可选，RLVR 场景下可用确定性判定替代）、参考模型。

**与 PPO 的差异（课程总结）**：其一，KL 惩罚放置位置因实现而异（可作为目标函数中的独立项，也可并入优势/奖励）；其二，优势计算方式不同——PPO 在 token 级用价值函数，GRPO 通常在补全级用组内标准化。讲义提到 GRPO 公式中优势写作 token 下标 $T$ 的函数，那只是通用写法，实践中多用补全级版本，因为更容易。

**已观察到的副作用**：在数学/推理任务上训练时，响应长度往往随训练增长，即使性能已进入平台期仍在增长。讲义给出的机制解释：目标函数中存在 $1/|o|$ 形式的归一化系数，短响应中每个 token 的贡献被放大。于是对于**坏答案**，模型相对更偏好较长的坏答案而非较短的坏答案——负优势在短回复中造成大幅下压，在长回复中只是轻微下压。这催生了后续修正：DAPO 改为对输出 token 总数归一化，使各 token 贡献均等；Dr. GRPO 直接去掉该归一化项。讲义还提到另外两处可能引入偏差的设计：用奖励标准差归一化会因输入难度不同引入偏差（可考虑移除）；对概率很小的动作，上下界使用同一 $\epsilon$ 几乎不给它被更多采样的空间，不利于多样性，可考虑对上下界取不同 $\epsilon$。

**GRPO 的遗留缺陷**：它没有显式的 token 级信用分配。用 Teddy 例子说明：无论中间推理步骤对错，所有 token 关联同一个最终奖励、同一个优势；长期来看模型平均而言能学到正确行为，但**非常低效**，损失函数的每一项在局部是有噪声的。若改走过程监督（process supervision），则需要专门的分步标注，且步骤内部仍有歧义（“Teddy 在厨房工作”——错在“工作”还是“在厨房”？），可能递归下沉到 token 级，等于又要训练一个奖励模型——而这正是当初放弃 PPO 想避免的。

### 8. On-policy distillation

**动机**：保留 on-policy 训练（基于模型自身输出学习），获得 token 级密集监督，且不额外训练任何模型。思路来自蒸馏——用下一 token 预测把强模型的信息传递给学生——但方向反过来：让学生自己生成，再让教师对学生的每个 token 打分。

**反向 KL**。KL 不对称：$D_{KL}(P\|Q) \neq D_{KL}(Q\|P)$。讲义给出的读法是“在由 P 支配的世界里，用 Q 近似有多糟糕”。标准蒸馏以教师为 P；on-policy 场景下以**学生**为第一参数，即反向 KL。其性质：当 $T_i \neq 0$ 而 $S_i \approx 0$ 时，该项对求和贡献小，对这类不匹配宽容；当 $T_i$ 很小而 $S_i$ 非零时，比值极大且权重非零，产生巨大惩罚。结合学生模型自由度通常小于教师，这使反向 KL 倾向于 **mode seeking**：学生学到教师分布的峰值。讲义诚实地补充：原始论文其实混合了两种 KL，反向 KL 未必显然更优。

**流程**：学生基于 prompt 生成补全；把 prompt + 学生已生成的 token 作为教师输入（teacher forcing），取教师在每个位置的下一 token 分布，与学生分布比较。Teddy 例子：学生说 “Teddy climbs”，教师认为 “climbs” 概率不高，于是被惩罚；“box” 在某些位置未被惩罚，直觉解释是：一旦上下文里 Teddy 已被描述为会攀爬，教师也可能认为“走路”在可能范围内——上下文会改变教师的判断。

**优势**：token 级密集监督；on-policy；实践中效果好，同等计算量下性价比更高；对参数受限（如低秩微调）更友好（讲义引用 Thinking Machines 的玩具消融研究，SFT 后再做 on-policy distillation 会大幅缩小仅 SFT 带来的性能差距）；**没有奖励模型就没有可被 hack 的东西**——若蒸馏把损失降到零，边界情形就是对齐到教师分布，这是良性的。

**局限一：需要教师**。若你在训练前沿模型、你自己就是最好的，就没人能教你。讲义给的两个应对：(a) **on-policy self-distillation**——教师就是同一个模型，但输入中注入了完整答案及通向答案的全部内容（因为教师调用是 teacher forcing，可自由构造输入），从而得到可与学生比较的漂亮分布；(b) **multi-teacher on-policy distillation**——按领域配备专家教师（各领域可用可验证奖励训练），蒸馏时对准该领域专家；讲义提到单教师后训练可能带来遗忘、且一组参数要服务多个目标，多教师经验上更高效。适用场景上，讲义建议较快的模型系列（如 Flash 档）用 on-policy distillation，前沿档更多用 GRPO 这类更吃算力的方法。

**局限二：教师能力构成上限**。与 GRPO 用真实标签作信号不同，这里学生对齐的是教师分布，而教师分布可能不完美、在目标领域覆盖不全。

## 关键公式与原则汇总

| 项目 | 内容 |
|---|---|
| 目标 | $J(\theta)=\mathbb{E}_{\tau\sim\pi_\theta}[R(\tau)]$，**最大化** |
| 策略梯度 | $\nabla_\theta J=\mathbb{E}[R(\tau)\nabla_\theta\log\pi_\theta(\tau)]$ |
| 更新方向 | 梯度上升：$\theta\leftarrow\theta+\alpha\nabla_\theta J$ |
| 重要性采样 | $\mathbb{E}_{\tau\sim\pi_\theta}[R]=\mathbb{E}_{\tau\sim\pi_{\text{old}}}\left[\frac{\pi_\theta}{\pi_{\text{old}}}R\right]$ |
| 优势（朴素） | $A_t\approx V_t - V_{t-1}$，$V$ 为 token 级价值函数 |
| GRPO 优势 | $A_i=(r_i-\text{mean}(r))/\text{std}(r)$，组内标准化 |
| KL | $D_{KL}(P\|Q)=\mathbb{E}[\log(P_i/Q_i)]$，不对称；反向 KL 倾向 mode seeking |

三条贯穿性原则：约束策略不偏离旧策略（裁剪）与参考策略（KL）；用基线/组内比较降方差；on-policy 采样昂贵、评估廉价，一切复用技巧都源于此。

## 常见误区

1. **把 L 当损失去最小化**。RL 阶段的目标函数通常要最大化；读 PPO 论文先确认方向。
2. **把公式里的 R 都当奖励**。PPO/GRPO 公式中的比值常记作 R，本课用 $\rho$ 以避免混淆。
3. **混淆三个策略**。$\pi_\theta$ 正在更新；$\pi_{\text{old}}$ 生成了当前这批数据；$\pi_{\text{ref}}$ 是冻结基准。裁剪针对前者与中者，KL 针对前者与后者。
4. **以为 RLHF 训练循环里有人类**。人类只在事先训练奖励模型时出现，循环内用的是冻结奖励模型。
5. **以为 GRPO 解决了信用分配**。它解决的是“免价值函数 + 降方差”，token 级信用分配仍未解决，只是靠长期平均来学。
6. **以为奖励越大更新越好**。没有基线时绝对奖励大小会放大方差；关键在于相对期望的比较。
7. **把 KL 当成对称距离**。KL 不对称，方向选择（正向/反向）直接影响学到的分布形态。
8. **以为奖励模型一定与真实目标一致**。讲义用“掌声”比喻说明 reward hacking 的风险，这正是需要 KL 约束的原因之一。
