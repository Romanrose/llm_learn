# 课程源文件

课程按网站首页的四个方向组织；完整课程介绍与网站链接见[总 README](../README.md#课程目录)。

- [编程与计算机系统](foundations/)：程序设计、计算机系统与并行计算。
- [大模型与智能体](models-agents/)：语言模型、强化学习、生成模型与 Agent 工程。
- [软件与产品开发](software-product/)：软件质量、需求发现、交互设计与 AI 产品。
- [机器人与 AI 硬件](robotics-hardware/)：桌面机械臂、嵌入式系统与端侧部署。

课程元数据统一放在 [website/catalog-data/courses](../website/catalog-data/courses/)，不在这里另建一份目录或生成流程。每门课程的 `paths` 指向其源目录，`outputs` 控制正式发布内容。
