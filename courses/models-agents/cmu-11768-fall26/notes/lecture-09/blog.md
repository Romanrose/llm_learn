## 这篇讲稿想解决什么问题？

上周我们讲了如何用监督微调（SFT）训练智能体。SFT 的思路很直观：拿一条人类或更强模型给出的"标准答案轨迹"，让模型学会在每一步都输出那个被示范的动作。但讲者（Daniel Fried）用一整个 Lecture 9 来说明：**SFT 的目标和我们真正想要的东西并不一样。**

这节课的定位是"三次强化学习讲座中的第一次"（逐字稿开头）。第一次讲最基本的策略梯度方法，第二次讲 off-policy 和稳定性技巧，第三次讲 RL 系统和超参数。贯穿全课的沙盒例子是 **Number Search**：一个隐藏整数在 1 到 16 之间，智能体最多猜四次，每次猜错环境回复"higher"或"lower"，猜对得奖励 1，超时得 0（Slides 第 2 页）。

这节课的主线可以概括为一句话：**把"模仿一条示范"换成"让高奖励轨迹更可能发生"**，然后一步步推导出怎么在没有梯度直通、环境不可微的条件下，仍然能对期望奖励求梯度。

## SFT 的三个问题

讲者在进入 RL 之前，先回顾了 SFT 的目标：最大化示范动作的对数概率之和（Slides 第 3 页）：

$$L_{\text{SFT}} = -\sum_t \log \pi_\theta(a_t^* \mid h_{1:t})$$

然后他列出 SFT 在智能体场景下的三个不匹配（Slides 第 4–6 页）：

**任务不匹配（Task mismatch）。** SFT 最大化的是"每一步示范动作的概率"，但我们想要的是"智能体完成任务的成功概率"。这两者相似但并不相同。原因有两层：第一，完成同一任务有多种方式——Slides 第 2 页给了两条都成功的轨迹 τ₁（8→12→10→11）和 τ₂（4→8→12→11），但一条示范只展示了一种；第二，有些动作明显比其他动作差，比如在"12→lower"之后绝不该猜 13，但 SFT 并不区分那些没有被示范的动作，只要它们不是目标 action，损失是一样的。

**数据不匹配（Data mismatch）。** 我们希望也能从次优数据中学习。Slides 第 5 页给出 τ₃ 和 τ₄ 两条失败轨迹（一个从 16 开始、一个从 1 开始然后线性递增），这两条轨迹本身不该被 SFT 模仿，但我们确实希望模型能从"这样做会失败"里获得信号。

**暴露偏差（Exposure bias）。** SFT 训练时，历史是固定的示范序列；但生成时，历史是模型自己产生的。Slides 第 6 页把这个画得很清楚：训练时是 `8 → higher → 12 → lower → 10 → higher → 11 correct`，生成时模型可能走到 `8 → higher → ?`，而它从未见过"自己猜错后"的分布。讲者的原话是：如果只在最优策略上训练，模型一旦采样出一个更低的数字，"可能就完全被打乱了，因为它在训练时没有见过那样的数据"。

## RL 的基本框架：轨迹、策略、奖励

RL 的思路（Slides 第 7 页）：让智能体自己生成轨迹，评估奖励，然后调整参数，使高奖励轨迹概率上升、低奖励轨迹概率下降。讲者指出这恰好同时回应了上面三个问题——目标直接是期望奖励（解决任务不匹配）、能从所有轨迹学习（解决数据不匹配）、轨迹来自当前策略即 on-policy（缓解暴露偏差）。

### 符号（Slides 第 8–12 页）

- **任务实例 x**：Number Search 里就是隐藏数字（本课固定为 11）。
- **观测 o、动作 a、奖励 r**：环境每步返回观测和奖励，智能体根据历史产生动作。
- **历史 h_t**：到第 t 步为止所有动作和观测的序列，`h_t = (o_0, a_0, o_1, …, o_t)`。策略 π_θ(a_t | h_t) 只依赖历史，不依赖隐藏的环境状态。
- **轨迹 τ = (o_0, a_0, r_1, o_1, …, a_{T-1}, r_T, o_T)**，奖励 R(τ) = Σ r_t。

Slides 第 9 页给了一张跨任务对照表：文本生成里任务实例是 prompt、动作是下一个 token、奖励是评判模型打分；Web agent 里任务实例是任务和网站、动作是点击/输入/滚动、奖励可以是已完成的子任务数；Number Search 里就是猜测。讲者特意强调，虽然大多数设置只在任务结束时给奖励，但课上讲的东西"也适用于具有中间奖励的设置"。

**轨迹概率**（Slides 第 12 页）是策略概率和环境概率的乘积：

$$p_\theta(\tau \mid x) = \prod_t \pi_\theta(a_t \mid h_t)\, P(o_{t+1}, r_{t+1} \mid h_t, a_t, x)$$

讲者的关键观察是：我们不知道环境概率 P，但可以通过与环境交互来从中采样。这被称为 RL 里"有点神奇"的地方——不需要知道环境模型，采样本本身就提供了求梯度所需的信息。有学生在这里问了 Markov 假设的问题，讲者回答说我们在处理的是 POMDP，下一个观测的概率必须依赖所有之前的观测和动作，因为你看不到底层状态。

> **学习者解释**：这里之所以"神奇"，是因为策略梯度推导只需要 log π_θ 对 θ 的导数，而环境那部分 P 与 θ 无关，求导时直接消失。采样提供的是 R(τ) 的估计，而 R(τ) 不需要可微。两者的分工让"不可微环境"不再是障碍。

### 目标函数（Slides 第 13 页）

$$J(\theta) = \mathbb{E}_{\tau \sim p_\theta(\cdot \mid x)}\big[R(\tau)\big]$$

Slides 第 13 页用四条轨迹算了具体的数字：π 给 τ₁ 0.30、τ₂ 0.20、τ₃ 0.25、τ₄ 0.25，前两条奖励 1、后两条奖励 0，期望奖励 = 0.30+0.20 = 0.50。训练的图景就是把概率质量从红色的失败轨迹搬到蓝色的成功轨迹上。

## 一个简单基线：ReST

在真正推导策略梯度之前，讲者先给了一个"非常简单的 SFT 修改"，叫 **Reinforced Self-Training，ReST**（Slides 第 14–16 页）。两步循环：从当前策略采样轨迹并计算奖励；用奖励过滤，把成功轨迹加入数据集，在上面做标准的 SFT。Slides 第 16 页的损失就是只在 R(τ)=1 的轨迹上求和的标准 SFT 损失。

讲者明确说这在技术上不算强化学习，但和高层思想很接近，而且"有二元化奖励就很适合"作为起点。有学生追问如何保证一定有正奖励的轨迹，讲者承认这是 RL 算法的核心难题，给出的方向包括：先用示范做冷启动（提到 R1 论文这类推理模型的做法）、课程学习（先训练能产生奖励的简单问题）、以及中间奖励/奖励塑形。

> **学习者解释**：ReST 和后面 REINFORCE 的关系，Slides 第 24 页写得很直白——在二元奖励下，REINFORCE 的损失（R(τ) 只取 0 或 1）恰好退化成"对成功轨迹做 SFT"。区别在于 ReST 会攒一个大数据集反复训练多个 epoch，而 REINFORCE 是采样一批、更新一次。

## 为什么不能直接反向传播

进入策略梯度前，讲者先解释了障碍（Slides 第 18 页）：

- 动作是**离散且采样**得到的。改变 θ 会改变动作概率，但只要没跨过某个"阶跃点"，采样得到的动作本身不变，所以样本对参数的导数几乎处处为零。
- **环境不可微**。讲者的原话很生动："你怎么对单元测试关于代码求导？"

虽然 p_θ(τ|x) 随 θ 变化，R(τ) 是在 rollout 之后才观测到的标量，两者无法端到端求导。

## 策略梯度（REINFORCE）推导

Slides 第 19 页把推导一步步写出来。核心是对期望奖励求梯度：

$$\nabla_\theta J = \nabla_\theta \sum_\tau p_\theta(\tau \mid x) R(\tau)$$

因为 R(τ) 不依赖 θ，梯度只作用在概率上。接着做**得分比率技巧（score ratio trick）**：分子分母同乘 p_θ，再用恒等式 ∇p/p = ∇log p：

$$\nabla_\theta J = \mathbb{E}_{\tau \sim p_\theta}\big[R(\tau)\, \nabla_\theta \log p_\theta(\tau \mid x)\big]$$

这就是 REINFORCE（Williams, 1992，Slides 第 19 页的引用）。

Slides 第 20 页把期望拆成三项可操作的东西：用采样得到 τ；从环境得到 R(τ) 这个标量； ∇_θ log π_θ(a_t|h_t) 用**和 SFT 相同的机制**计算。

### 轨迹对数概率（Slides 第 21 页）

$\log p_\theta(\tau \mid x) = \sum_t \log P(o_t, r_t \mid h_t, a_t, x) + \sum_t \log \pi_\theta(a_t \mid h_t)$

第一项与环境概率相关，**不依赖 θ**，求导时是常数，直接消失。于是：

$$\nabla_\theta \log p_\theta(\tau \mid x) = \sum_t \nabla_\theta \log \pi_\theta(a_t \mid h_t)$$

还有一处细节：一个动作 a_t 可能由多个 token 组成（比如一次复杂的工具调用），动作的对数概率是各 token 对数概率之和：

$$\nabla_\theta \log \pi_\theta(a_t \mid h_t) = \sum_{k=1}^{m_t} \nabla_\theta \log \pi_\theta(u_{t,k} \mid h_t, u_{t,<k})$$

### 实现（Slides 第 22 页）

Slides 第 22 页给了一张带 masking 的示意图：彩色的 token 是策略采样出来的，灰色的是 prompt、观测、脚手架添加的内容。损失是：

$$L_{\text{PG}} = -R(\tau) \sum_{t:\, m_t = 1} \sum_k \log \pi_\theta(u_{t,k} \mid u_{<t})$$

讲者感叹说，他第一次看到在复杂任务上用 REINFORCE 的代码（提到一篇叫 “Deal or No Deal” 的论文）时很惊讶，因为实现"基本上就是做一个 SFT 梯度计算，然后把那个梯度乘以一个奖励"。

### 训练循环（Slides 第 23 页）

采样任务实例 → 在它们上面采样轨迹并算奖励 → 用奖励加权动作对数概率 → 反向传播、更新 θ、重新采集。

## 奖励应该是相对的：基线（Baseline）

讲者说"人们很少会直接开箱即用地运行标准的 REINFORCE"，最大的动机来自 Slides 第 26 页：**奖励应该是相对的**。看两条轨迹——一条全部正确（R=1），每条动作都被奖励 1 加权；另一条 τ₃（16→8→9→10 timeout，R=0）。在基本 REINFORCE 里，第二条根本不产生任何梯度，因为奖励是零、乘出来就是零。

但我们明明希望"学会不做这个"。讲者的另一种说法是：更新应该取决于**策略在这个例子上通常表现如何**。如果模型 95% 的情况下都能拿 1，那 5% 的愚蠢错误应该得到一个很重的反向更新。

### 优势函数（Slides 第 27–28 页）

Slides 第 27 页把优势定义成：

$$A^\pi(h, a) = Q^\pi(h, a) - V^\pi(h)$$

前者是"采取这个动作之后能拿到的期望奖励"，后者是"从 h 出发的期望奖励"。讲者用 Number Search 举了一个很好的例子：

假设已经猜了 8（得到 higher）、猜了 12（得到 lower），那么数字在 9、10、11 之间，还剩两次机会。此时：
- **猜 11 很糟**：它落在范围的一端。如果不对，还剩两个候选但只剩一次猜测，A^π(h, 11) < 0。
- **猜 10 很好**：无论对错，剩下一个候选还剩一次机会，可以往高或往低猜，A^π(h, 10) > 0。

Q^π 和 V^π 我们都不知道，所以用采样的奖励来估计优势：

$$\hat{A}_t = R(\tau) - b(h_t)$$

Slides 第 28 页列了几种基线选择：常数、奖励的滑动平均、训练出的价值模型 V_φ(h_t)（即 actor-critic / PPO）、以及**组内均值**（GRPO，下一节）。

### 基线不引入偏差（Slides 第 29 页）

Slides 第 29 页给了一个简短的证明。所有只依赖历史 h_t 的基线都不会让梯度估计有偏。证明的关键一步是：

$$\mathbb{E}_{a \sim \pi_\theta}\big[b(h) \nabla_\theta \log \pi_\theta(a \mid h)\big] = b(h) \sum_a \nabla_\theta \pi_\theta(a \mid h) = b(h) \nabla_\theta \sum_a \pi_\theta(a \mid h) = b(h)\nabla_\theta 1 = 0$$

也就是"概率之和恒为 1，梯度为零"。

> **学习者解释**：这个证明的含义是：减去一个和历史相关的常数，梯度期望不变，但样本的方差可以小很多。这正是为什么几乎所有实用的策略梯度算法都会减去某种基线。

### 双臂老虎机示例（Slides 第 30–33 页）

讲者用一个只有两个动作、只有一个参数 θ 的简化例子把基线的作用讲得非常具体（他说"基线对我来说一直有点神秘，做这些可视化也是为了说服自己"）。

设 p = σ(θ) 是选 A 的概率，θ = −1.1 给出 p = 0.25。A 奖励 1、B 奖励 0。这个策略是**坏的**，因为它把更高概率放在了没奖励的动作上，我们希望 θ 变得更正。

不使用基线时（Slides 第 30 页）：
- 采样 A：R=1 × ∂/∂θ log π = 1 × (1−p) = +0.75
- 采样 B：R=0 × ∂/∂θ log π = 0

**如果采样 B，梯度是 0**——这就是讲者一直强调的"失败轨迹不给信号"的现象在最小例子里的体现。

加入基线 b = 0.5 后（Slides 第 31 页）：
- 采样 A：Â = +0.5 × 0.75 = **+0.375**（无基线是 +0.75）
- 采样 B：Â = −0.5 × (−0.25) = **+0.125**（无基线是 0）

两个样本都变成正的、都朝正确方向更新 θ，而且都更接近真实梯度 0.1875。

Slides 第 32–33 页给出方差对比：无基线时梯度样本的标准差是 **0.325**，基线 0.5 时是 **0.108**，而两者的运行平均都收敛到 **0.188**（即真实梯度 0.1875 的采样近似）。讲者的总结是：期望不变，方差变窄。

### 基线的局限与 reward-to-go（Slides 第 34–35 页）

Slides 第 34 页诚实地列出：基线能标记一条轨迹比预期好还是差、能降低方差；但**不能解决 credit assignment**——同一条轨迹里所有动作共享同一个 Â；而且估计 V^π 可能需要单独的价值模型。

Slides 第 35 页给了一个处理中间奖励的技巧：**reward-to-go**。如果一个动作 a_t 之后的奖励才与它有关，那就只用后续奖励：

$$R_t = \sum_{t' = t+1}^{T} r_{t'}$$

讲者解释说，早于 a_t 的奖励不依赖 a_t，丢掉它们可以降方差而不引入偏差。Number Search 只在最后给奖励，所以对每个动作都有 R_t = R(τ)。

## 组相对优势：GRPO 与 DrGRPO

（Slides 第 36–42 页）

讲者用最后一段时间介绍了 GRPO（Group Relative Policy Optimization，来自 DeepSeekMath）的**简化版本**。动机是：好的基线需要估计策略下的期望奖励，而训练一个单独的价值模型很贵（Slides 第 42 页把它对照 PPO）。GRPO 的思路是**对同一个任务实例采样多次**，用组内奖励的均值作为基线。

Slides 第 37 页给了四条 Number Search 轨迹（两条 R=1、两条 R=0）的完整计算：R̄ = 0.5、σ_R = 0.5，中心化后 ±0.5，再除以 σ_R 得到优势 ±1。

Slides 第 38 页把 GRPO 损失写成：

$$-\sum_i \frac{1}{G}\sum_{j=1}^{G} \hat{A}_{ij} \sum_t \log \pi_\theta(a_{ij,t} \mid h_{ij,t})$$

并强调**每个任务实例有自己的 R̄_i 和 σ_i，各自归一化**。页脚注明这是"针对当前策略轨迹的写法，不含论文中的 ratio、clipping 或 KL 项"。讲者也明确提醒，原论文的损失有额外项（ratio、clipping、对策略偏离起点的正则），Graham 的下一次讲座会讲，今天只讨论 GRPO 内部的优势函数。

### DrGRPO 的两处改动（Slides 第 39–40 页）

讲者说这两处改动"你也会在作业中做"（指 Assignment 3，但本讲稿不涉及具体题目）：

1. **去掉除以标准差**。理由是除以 σ_R 会让优势不再意识到问题难度——相当于把所有难度范围重新缩放为标准化的。Slides 第 39 页的理由栏写着：σ_R 是组内测量的，所以实例间不同；几乎总是通过或几乎总是失败的实例 σ_R 很小，反而会占更大权重。
2. **去掉除以生成长度**。原来的 GRPO 会除以 |y_j|，这会让一个又长又错的回答按 token 惩罚得更轻，于是"策略会漂向更长的错误答案"。DrGRPO 改为除以一个全局常数 C（论文里用生成预算）。

Slides 第 40 页给出 DrGRPO 的每 token 系数示意：同一条轨迹的每个生成 token 共享该轨迹的优势：

$$L_{\text{DrGRPO}} = -\frac{1}{G}\sum_{j=1}^{G} \frac{1}{C} \sum_{t:\, m_{j,t}=1} \hat{A}_j \log \pi_\theta(u_{j,t} \mid u_{j,<t})$$

### 退化组（Slides 第 41 页）

Slides 第 41 页指出一个重要边界：如果组内所有奖励都相同，优势全为零，贡献的梯度也是零。全失败 [0,0,0,0] 说明对当前策略可能太难；全成功 [1,1,1,1] 说明可能太简单。讲者列出几个可选做法：换任务实例、扩大探索、加入示范，或者提供更有信息量的奖励（奖励塑形，比如给"找到正确文件"发奖励）。

Slides 第 15 和 37 页引用了 ReST、ReST-EM、DeepSeekMath、DrGRPO，均以幻灯片上的论文标签为准。

## 把这节课的方法放在一起看

Slides 第 44 页给了一张非常清楚的对照表。所有方法都在用某种权重 w_t 加权"智能体实际采取的动作"，区别只在权重：

| 方法 | w_t |
|---|---|
| ReST-EM | 成功轨迹为 1，否则为 0 |
| REINFORCE | R(τ)，轨迹的奖励 |
| GRPO / DrGRPO | Â，相对于同任务实例其他 rollout 的奖励 |

统一的形式是：

$$\nabla_\theta J = \sum_t w_t \nabla_\theta \log \pi_\theta(a_t \mid h_t)$$

Slides 第 45 页把三个问题收尾：任务不匹配（目标直接是期望奖励）、数据不匹配（能用次优轨迹里学到的信息，只要基线合适）、暴露偏差（同策略轨迹让模型学会从自己的错误中恢复）。
