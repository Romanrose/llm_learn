    What is an Agent?




    An agent perceives its environment through sensors and acts upon the
    environment through actuators.
    Environment: code repo, website, application, real world.
    States/observations: messages, files, webpages, tool results.
    Actions: text, file edits, API calls, shell commands, physical movements.
    Rewards: test cases, task completions, LLM judges, user feedback.

     Prompt Optimization
     Main challenges of prompt evolution:
     1. How to optimize over discrete non-differentiable tokens. Need techniques from
     discrete optimization.
     → Gradient-based or search-based.
     → Gradients to update prompt directly vs update LLM that generates prompts.


     2. Search space is extremely high-dimensional (space of all long strings). How to
     reduce the space through modular and composable prompts?
     → Text vs code modules, software engineering best practices.

      DSPy Programming
      DSPy pushes away from manipulating free-form strings and closer to programming (composing modular operators to
      build text transformation graphs). A compiler automatically generates optimized LM invocation strategies and prompts.




[Khattab et al., DSPy: Compiling Declarative Language Model Calls into Self-Improving Pipelines. arXiv 2023]

      DSPy Programming
      Optimizing modules in DSPy




      3 ways optimization is performed:

      1: Candidate Generation. The compiler (recursively) finds all unique Predict modules (predictors) in a program and
      generates candidate values for its parameters: instructions, field descriptions, demonstrations (input–output pairs).

      2: Parameter Optimization. Use hyperparameter tuning algorithms (e.g., random search or Bayesian optimization) to
      select among candidates: recall discrete optimization problem.

      3. Higher-Order Program Optimization. Modify the control flow of the program e.g., ensemble to bootstrap multiple
      copies of the same program, running them in parallel and aggregating (e.g., majority voting).

[Khattab et al., DSPy: Compiling Declarative Language Model Calls into Self-Improving Pipelines. arXiv 2023]

     3 Ways to Deal with Long Context
     1. New architectures: sliding window, sparse, linear attention etc.
     → Can improve model efficiency and reduces compute.
     → But needs re-design and re-training.

     2. Long-context training: short-to-long training, synthetic data, extend position encodings
     → Helps expands the context window, simple to use.
     → But requires data and can be expensive.

     3. Context management: Context summarization, memory systems, RAG
     → Improves the information pipeline, can scale.
     → Depends on retrieval and memory quality.
