     Background - Cap set problem & Bin-packing
     1. Cap set problem: How many points can you select from {0,1,2}^n without
        including three distinct points on a line?
        a. In 8 dimensions, each point is an eight-entry vector, such as
            (0,2,1,0,1,2,2,0).
        b. Select as many of the 6,561 points in {0,1,2}^8 as possible, with no three
            distinct points on a line.

     2. Bin-packing problem: How can we pack items of different sizes into the fewest
        bins, without exceeding any bin’s capacity?
        a. For example, suppose each bin has capacity 10, and the items have sizes
            6, 5, 3, 2, 2, 2: A valid packing uses 3 bins: [6,3], [5,2,2], [2].
        b. In online bin packing, items arrive one at a time. You must place each item
            immediately.

     FunSearch Breakdown - Search Space
     Search space: the set of candidates an optimizer can explore.

     FunSearch searches over Python functions with given input and output format.

     Cap sets: priority(element, n) ranks which vector to add next.
     Bin packing: heuristic(item, bins) ranks where to place an item.

     The output is a reusable program that constructs solutions.

     FunSearch Breakdown - Evolutionary algorithms
      Evolutionary algorithms improve a population through repeated selection,
      variation, and evaluation.
      FunSearch uses an LLM to generate variations of sampled programs.
32



     FunSearch Breakdown - Programs Pool & Exploration
      1. Initialize each island with a seed program

      2. Grow the population within each island
         a. Sample parents from the existing programs in this island
         b. Generate a child program and add it to the same island

      3. Remove the lower performing islands

     Open Challenges

      - Distribution shift from ultra-long contexts
     How does model behavior change as context length grows, and how robust
     are optimization/discovery methods under these induced distribution shifts?

      - Genuine discovery beyond verifiable domains
     Can LLMs generate genuinely novel discoveries when correctness or
     progress cannot be easily verified by an automated evaluator?

      - Faster Adaptation
     Can models learn useful design principles from fewer experiments,
     enabling better decisions and designs with a smaller experimental budget?
