## 一、学习目标

完成本讲后，应能：

1. 用概率论语言形式化「生成一个对象」：数据是向量，生成目标是采样自数据分布 \(p_{\text{data}}\)。
2. 理解生成模型的基本契约：从一个已知初始分布（几乎总是标准高斯）出发，经某个过程得到数据分布样本。
3. 掌握 ODE 的四个对象：轨迹（trajectory）、向量场（vector field）、初始条件、流（flow），并理解「流 = 所有初始条件下 ODE 轨迹的集合」。
4. 理解流模型（flow model）：神经网络 = 参数化向量场；采样 = 从高斯采样初始点并数值模拟 ODE。
5. 理解 SDE 相对 ODE 的扩展：加入扩散系数（diffusion coefficient）与布朗运动（Brownian motion），得到随机轨迹。
6. 理解扩散模型（diffusion model）：参数化向量场 + 固定扩散系数，模拟 SDE 得到数据分布样本。
7. 知道本讲只完成「形式化与部署」，训练算法（flow matching / score matching）在后续课程。

## 二、课程主线

本讲的主线可以概括为一条递进链：

**数据 → 分布 → 生成目标 → ODE/流 → 流模型 → SDE/布朗运动 → 扩散模型 → 训练问题（留待下讲）**

课程明确说明其定位：不只展示算法，而是推导算法；理论聚焦「最少但必要」的数学；实验课要求把所学实现为真正的算法，且这是评分的主要方式。课程还明确提示：SDE 的数学更重，但核心始终是 flow 部分；若扩散部分过于复杂，应优先掌握 flow 部分，因为 flow 模型本身已是当前先进方法之一。

后续课程路线（按本讲概述）：flow matching 训练、score matching 训练、guidance（以提示词为条件）、图像生成器架构与潜在空间、离散扩散与相关高级话题。

## 三、核心概念

### 1. 数据即向量

图像表示为「高 × 宽 × 3 通道」的矩阵，展平即向量；视频是帧的序列，可表示为矩阵；蛋白质结构中每行对应原子/氨基酸及其空间坐标。课程原意：无论模态如何，展平后都作为向量处理，因此「生成某物」在底层就是「生成一个向量」。

### 2. 用分布替代主观判断

课程用「一张狗的照片」的四张候选图说明：好坏判断是主观的，数学无法直接处理。形式化方式是引入数据分布 \(p_{\text{data}}\)，把「这张图有多好」近似为「它在数据分布下的似然有多大」。似然为零则不可能被采样到；大于零则可能。采样记为 \(Z \sim p_{\text{data}}\)。

- **数据集**：来自该分布的有限样本集合；互联网公开图像被视为对真实数据分布的近似。
- 课程强调：训练时「从分布采样」实际指抽取一个数据点。

### 3. 条件生成

最终目标是条件分布：给定条件变量 \(Y\)（如文本提示词），从 \(p(\cdot \mid Y)\) 采样。课程明确说明本讲与前两讲先聚焦无条件情形，条件化是第三讲主题，理由是条件化更难，但一旦掌握无条件情形，条件化并不难。

> 整理者注：关于「新颖性」的提问，讲师回答的判据是「生成点是否在数据集中」，并指出评估生成模型有各种指标，将在图像生成部分稍作讨论；本讲未展开具体指标。

### 4. 生成模型的目标（课程原意）

存在初始分布（几乎总是标准零均值、单位方差的多变量高斯），从中采样一个点（对图像而言看起来就是噪声），输入生成模型，输出一个数据分布样本。课程特别说明：这是「目标」而非「实现方式」；生成模型不必是单个网络，可以是过程性定义；也并非所有生成模型都严格是「噪声进网络出」，应视为更大的黑箱。

### 5. ODE：轨迹、向量场、初始条件

- **轨迹**：定义在单位区间 \([0,1]\) 上的函数 \(X\)，每个时刻 \(t\) 赋予一个向量 \(X_t\)。
- **向量场**：为每个位置与时间赋予一个向量（不只是方向，讲师在提问中明确：是实际向量，非单位向量）。课堂举例：引力场、天气图上的风向。
- **ODE**：由初始条件 \(X_0\) 与演化规则
  \[
  \frac{dX_t}{dt} = u_t(X_t)
  \]
  组成。直观：每一点的速度由向量场给定；如风中飘动的羽毛是該 ODE 的一条轨迹。
- 讲师确认：初始条件隐含速度信息，因为演化规则对所有 \(t\) 成立（包括 \(t=0\)）；下一状态只依赖当前状态，具有马尔可夫/无记忆性质。

### 6. 流（flow）

流 \(\psi\) 是一个函数：输入初始条件与时间，返回该时刻的位置；它对应 ODE 对所有初始条件的全部轨迹解。形式化条件：

\[
\psi_0(X_0) = X_0 \quad (\text{时间零为恒等映射})
\]
\[
\frac{\partial \psi_t(X_0)}{\partial t} = u_t(\psi_t(X_0))
\]

课程可视化：红点初始均匀网格随流演化、空间被可微地扭曲；数学上流是微分同胚（diffeomorphism）。

### 7. 解的存在唯一性与课堂反例

课程提问：是否任意 ODE 都有唯一解？讲师给出一维反例：
\[
u_t(x) = 2\sqrt{x},\quad X_0 = 0
\]
则 \(X_t \equiv 0\) 与 \(X_t = t^2\) 都是解（验证：后者导数 \(2t = 2\sqrt{t^2}\)）。结论：一般 ODE 未必有唯一解。

课程给出的避免条件：向量场连续可微且具有有界导数，则 ODE 有唯一解。讲师说明该条件在机器学习中通常成立，因此课程可直接假设解与流存在；唯一性主要是数学工具需要（后续要用「流最终到哪里」等性质），并半开玩笑地说或许可以写论文研究不满足条件的网络，但课程范围内不需要。

> 整理者注：反例中「零解」与「\(t^2\)」在 \(t \ge 0\) 上成立；课程用它说明非唯一性，未展开更细的适定性讨论。

### 8. 线性 ODE 的解析解

\[
u_t(x) = -\theta x
\]
\[
\psi_t(X_0) = e^{-\theta t} X_0
\]
验证：\(t=0\) 时为 \(X_0\)；对时间求导用链式法则得 \(-\theta e^{-\theta t} X_0 = -\theta \psi_t(X_0)\)。课程强调：这是课程中少数（几乎是唯一）出现解析解的情形；实际感兴趣的情形必须数值模拟。

### 9. ODE 的数值模拟与权衡

给定向量场、初始条件、步数：步长 \(h = 1/\text{步数}\)；迭代
\[
X_{t+h} = X_t + h\, u_t(X_t)
\]
即沿向量场方向走一步。课程指出这是熟悉的一阶格式。核心权衡：步长小 → 模拟更准但计算更贵；步长大 → 更高效但误差更高。讲师明确要求记住这一权衡。

### 10. 流模型（flow model）

- 神经网络 = **参数化向量场** \(u_t^\theta\)；理论对本课程大部分内容适用于任意架构，架构差异在后续讨论（蛋白质、图像、视频各有专用架构）。
- ODE 本身确定性，无法从分布采样；因此令初始条件服从初始分布（几乎总是高斯）：\(X_0 \sim \mathcal{N}(0, I)\)，再模拟 ODE。
- 目标：设计网络参数，使终点 \(X_1\) 服从数据分布。课程强调这只是提出目标，尚未给出实现方法。
- 采样/部署算法：从高斯采样初始点；每一步查询神经网络得到向量场方向并前进；返回终点。讲师明确：训练后 \(\theta\) 固定；训练期间才改变参数。
- 课程展示用该算法模拟的流模型生成视频，强调「采样其实相当简单」。

### 11. SDE：随机轨迹与扩散系数

- **随机过程**：可理解为随机轨迹；\(X_t\) 是随机变量；同一起点多次采样结果不同。
- **扩散系数**：依赖时间的非负数 \(\sigma_t\)，表示注入的噪声量/随机性量；课程明确在扩散模型中它是固定设计选择，不是神经网络（原则上也可依赖状态，讲师提到自己写过相关论文，但当前先进方法不这么做）。
- **布朗运动** \(W_t\)：\(W_0=0\)；高斯增量（\(W_t - W_s\) 高斯的，方差随时间差线性增长）；独立增量（早期变化不决定后期变化）。课程说明其存在性需在随机微积分课中构造，且条件并不随意（例如把标准差改为随时间线性增长则不存在这样的过程）。
- **SDE 记号**：
  \[
  dX_t = u_t(X_t)\,dt + \sigma_t\, dW_t
  \]
  课程先做纯记号改写：把 \(\dot X_t = u_t(X_t)\) 写成微分形式，数学含义不变；SDE 即 ODE 部分加随机项。
- **模拟**：每步
  \[
  X_{t+h} = X_t + h\,u_t(X_t) + \sigma_t \sqrt{h}\,\varepsilon,\quad \varepsilon \sim \mathcal{N}(0,I)
  \]
  讲师解释 \(\sqrt{h}\) 的原因：方差随时间线性增长，需可加性（方差可加、标准差不可加），故用步长平方根缩放。若 \(\sigma=0\)，退化为 ODE。
- **SDE 的严格含义**：不用导数表述，而用增量表述——误差项的方差除以 \(h\) 后趋于零；课程强调这是「无导数语言」的等价陈述，因为布朗运动处处不可微、路径连续但无限长。
- **存在唯一性**：与 ODE 同样的条件（向量场连续可微、有界导数）下 SDE 解存在；唯一性指轨迹的（联合）分布唯一，其严格构造涉及测度论，课程明确跳过。
- 讲师提到 ODE 的高阶模拟器用于 SDE 是可能的，但已知的 ODE 模拟器远多于 SDE 模拟器；本讲只给一阶格式。

### 12. Ornstein–Uhlenbeck 过程（课堂例子）

线性向量场加常数扩散系数：\(\sigma=0\) 时退化为前述线性 ODE；\(\sigma\) 增大，路径更粗糙、随机性更强。课程用它展示「扩散系数控制粗糙度」的直观。

### 13. 扩散模型（diffusion model）

定义：用 SDE 而非 ODE 把噪声转换为数据；神经网络向量场 + **固定**扩散系数；目标同样是终点服从数据分布。采样与流模型相同，只是每步多加缩放的高斯噪声。课程展示蛋白质结构生成：ODE 版本与 SDE 版本对比，SDE 随机性明显更大。

课程明确 SDE 的动机（部分为经验性/设计性，非本讲定理）：
- 随机演化允许在每一步构造搜索树、做搜索/优化，而确定性 ODE 轨迹无法在中途改变；
- 随机性经验上带来更多多样性（如更多样化的图像）；
- 讲师反复强调：随机性在此阶段是「工具」，核心仍是向量场（flow 部分）。

## 四、关键公式与原则汇总

| 对象 | 公式/原则 | 课程要点 |
|---|---|---|
| ODE | \(\dot X_t = u_t(X_t),\ X_0\) 给定 | 速度由向量场给定；马尔可夫性 |
| 流 | \(\psi_0(X_0)=X_0,\ \partial_t \psi_t = u_t(\psi_t)\) | 所有初始条件轨迹的集合；微分同胚 |
| 存在唯一 | \(u\) 连续可微且有界导数 | 课堂反例说明一般情形不唯一；ML 中可直接假设 |
| 线性 ODE | \(u_t(x)=-\theta x \Rightarrow \psi_t=e^{-\theta t}X_0\) | 课程中少见的解析解 |
| ODE 模拟 | \(X_{t+h}=X_t+h\,u_t(X_t)\) | 步长-精度-计算量权衡 |
| 流模型 | \(X_0\sim\mathcal{N}(0,I)\)，模拟 ODE，目标 \(X_1\sim p_{\text{data}}\) | 网络 = 参数化向量场；\(\theta\) 训练后固定 |
| SDE | \(dX_t=u_t(X_t)dt+\sigma_t dW_t\) | ODE 部分 + 随机项；\(\sigma_t\ge 0\) |
| 布朗运动 | \(W_0=0\)；高斯增量；独立增量 | 连续、处处不可微、路径无限长 |
| SDE 模拟 | \(X_{t+h}=X_t+h u_t+\sigma_t\sqrt{h}\,\varepsilon\) | \(\sqrt{h}\) 来自方差可加性；\(\sigma=0\) 退化为 ODE |
| 扩散模型 | 同上，\(\sigma_t\) 固定非网络 | 目标同流模型；采样多一步噪声 |

**贯穿原则**：本讲只做「定义目标 + 部署采样」，不做训练；训练算法是下一讲 flow matching 的主题，课程称其「相当简洁、高效，是所有这些的基础」。

## 六、常见误区

1. **把「生成模型」等同于「一个神经网络」**：课程明确生成模型可以是过程性定义、更大的黑箱；本讲框架中它是「参数化向量场 + （可选）扩散系数 + 初始分布 + 模拟过程」。
2. **把向量场当成方向（单位向量）**：课堂提问确认它是实际向量，含速度信息。
3. **认为任意 ODE 都有唯一解**：课堂反例 \(u=2\sqrt{x}, X_0=0\) 给出两个解；课程靠连续可微 + 有界导数假设规避。
4. **把 SDE 当成「ODE 加噪声」的平凡推广而忽略定义**：课程强调 SDE 的严格含义要用增量语言表述，因为布朗运动处处不可微；模拟中 \(\sqrt{h}\) 缩放来自方差可加性，不是随意选择。
5. **误以为扩散系数要由神经网络学习**：课程明确扩散系数是固定设计选择（常数或仅依赖时间），当前先进方法不使其依赖状态；可学习的部分是向量场。
6. **误以为本讲已讲训练**：本讲只设定目标并给出采样算法；「为什么不直接用一个网络一步输出样本」的提问，讲师回答是训练算法问题——理想情况是一步生成，但尚无稳定可扩展的训练算法（GAN 能一步生成但如今使用较少）。
7. **误以为 ODE 与 SDE 生成分布必然不同**：课程回答原则上目标分布相同（因而熵相同），但训练误差、模拟误差等会使实际结果不同，后续课程讨论。
8. **忽略步长权衡**：步长小更准但更贵；这是采样阶段必须意识到的工程折中。
