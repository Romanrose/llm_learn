# 从向量场到速率矩阵：MIT 6.S184 第六讲中的离散扩散与离散流匹配

## 导语：当“扩散”不再是扩散

在 MIT 6.S184 这门以随机微分方程（SDE）为主线的生成模型课程里，前四讲建立了一整套连续状态空间的语言：流模型、扩散模型、流匹配（flow matching）、分数匹配（score matching）、引导（guidance），以及如何用潜空间（latent spaces）搭建图像与视频生成器。第六讲是课程的最后一讲，它做了一件颇具张力的事——把上述原理整体搬到离散状态空间，去处理语言、蛋白质这类由离散 token 构成的数据。

有趣的是，讲师一开始就澄清了一个容易误解的命名：今天在 AI 社区里被广泛称为“扩散语言模型”的东西，“实际上它们并不是真正的扩散模型……这里没有扩散，没有 SDE，也没有 ODE，也没有流”。真正的数学骨架是连续时间马尔可夫链（continuous time Markov chains, CTMC）。这一讲的核心主张因此可以概括为一句话：流匹配的学习配方并不依赖连续空间本身，它可以被系统地翻译成 CTMC 的语言，而翻译之后，训练目标会退化为一个我们极其熟悉的东西——分类。

这篇文章将沿着讲师的论证顺序展开：先建立 CTMC 与速率矩阵（rate matrix）的基本对象，再说明为什么必须施加因子分解条件（factorization condition），然后走一遍从条件概率路径到边缘速率矩阵的完整配方，最后落到离散流匹配损失、掩码扩散语言模型（masked diffusion language model）的实践形态，以及这一讲在整个课程学习路径中的位置。

## 一、换一个状态空间：从 R^D 到 V^D

连续情形里，状态空间是向量空间 R^D，模型学习的是向量场，告诉你“往哪个方向走”。讲师强调，在离散空间里这个直觉失效了：“去到字母 X 的方向是什么？我不知道从字母 Y 进入字母 X 的方向会是什么。所以我们能做的唯一事情就是切换。”

于是需要重新铺设基础对象。首先是词表或字母表（alphabet）V，包含 V 个字符——可以是英文字母、字节对编码（byte pair encoding）的 token、词，也可以是蛋白质里的氨基酸。讲师特意说明这是一个抽象的字母表，选什么由使用者决定，但在实践中这个选择可能非常重要。状态空间随之变成 V^D：一个状态 X 就是来自字母表的字符序列。

接下来是速率矩阵 Q_T(Y|X, T)，它接收两个状态和一个时间，输出一个非负数，直观含义是“从 Y 切换到 X 的速率”。它受两个条件约束：非负性，以及对角元 Q_T(X|X) 等于所有向外速率之和的负值，从而矩阵按列求和为零。讲师把这一条件称为一种平衡条件，并顺带提醒行列约定只是记号问题。

CTMC 本身则是一个无记忆的随机过程，由转移核（transition kernel）P_T(X_{T+H}=Y | X_T=X) 刻画。它与速率矩阵的关系是：转移概率在零偏移处的导数由速率矩阵给出。讲师用一个两状态例子说明这一点：设从 A 到 B 的速率为 lambda，则由列和为零可知 A 到 A 的速率为负 lambda；对应的转移概率呈现指数形式，而当 h 趋于无穷时，指数项衰减，过程收敛到两个状态上的均匀分布——“我们只是在两个状态上均匀分布，也就是忘记我们原来在哪里”。

这个例子看似平凡，却预示了整讲的走向：CTMC 的长期行为是趋向无信息，而生成建模要做的，是把这个方向反过来。

## 二、因子分解条件：让指数级的状态空间变得可处理

把 CTMC 用于机器学习，就是把速率矩阵参数化。但讲师随即引入了一个关键约束，称为因子分解条件：速率矩阵在 Y 与 X 相差超过一个位置时必须为零。用讲师的话说，如果两个序列在超过一个索引上不同，它们就不是邻居；用汉明距离（Hamming distance）的术语，就是距离大于一时速率为零。

为什么这个约束是必要的？讲师给出了一个量级论证：若不施加稀疏性，状态空间的基数是 V 的 D 次方，指数级增长，“所有可能的英文句子组成的集合是指数级大的。我们不可能在没有这个稀疏性约束的情况下存储这个矩阵的一列”。而有了因子分解条件，神经网络只需输出一个形状为 D 乘以词表大小 V 的矩阵——对每个位置、每个词表点给出一个速率，随维度线性增长。

讲师用一张对比图说明这一点：左侧是没有因子分解条件的速率矩阵，从每个 X 可以到每个 Y；右侧施加约束后，只能从 X 到一个沿单一维度不同的 Y。值得注意的是，讲师补充道，随时间推移仍可能发生两次切换从而到达其他状态，但“速率本身在那些地方是零”。这句话点出了 CTMC 与离散流匹配之间的微妙关系：稀疏性约束的是一阶的瞬时速率，而不是过程的长期可达性。

## 三、采样：用泰勒展开把速率变成可采样的分布

有了模型，下一步是采样。初始分布不能再是高斯——“高斯分布在离散状态空间中是没有定义的”——于是改用集合 S 上的均匀分布，即每个点等概率。另一个工具是离散的 delta 函数：相等时为一，不等时为零。

天真的采样方案是直接按转移概率分布采样下一个状态，但讲师指出这行不通：“因为我们不知道这些转移概率。我们唯一隐式定义的是速率矩阵。”解决办法是对步长 H 做围绕零的泰勒展开：零阶项是 delta（没有时间流逝时，留在原地的概率为一），一阶项是 H 乘以速率矩阵。讲师强调，这个近似之所以构成一个合法的分布，恰恰是因为速率矩阵对 Y 求和为零——“我们设计速率矩阵的方式使得我们刚刚定义的采样过程实际上是有效的”。

在回答提问时，讲师进一步解释了这一阶近似的意义：因子分解条件定义的正是一阶的速率；更高阶的事件，比如某个 token 在一个区间内从 X 跳到 Y 再跳到 Z，是被忽略的部分，“这实际上就是这种方法累积的误差”。

实际算法因此是：从初始分布采样 X_0，把时间步长设为一除以 N，每一步计算因子化的跳跃速率，对序列中每个位置按“H 乘以速率”构造分类分布（categorical distribution）并采样更新。讲师也提到实践中会并行地做这些更新，而非写成循环。

## 四、配方重演：从条件路径到边缘速率矩阵

进入训练部分，讲师明确说：“本质上从我的 ODE 幻灯片以来什么都没有改变，除了我把 ODE 这个词替换为 CTMC，并且我把初始分布从高斯替换为均匀分布。”

连续流匹配的配方是：条件概率路径与边缘概率路径，导出条件向量场与边缘向量场，再导出条件损失与边缘损失。离散版本逐项对应：条件概率路径与边缘概率路径，条件速率矩阵与边缘速率矩阵，以及形式相同的流匹配损失。讲师把后两者合并展示以简化，但强调配方本身一致。

条件概率路径现在是一族概率质量函数（probability mass function）：对 S 中的 X 求和为一、处处非负；在时间零处等于与数据点无关的初始分布，在时间一处等于以数据点为中心的 delta。边缘路径则是对数据分布求和而非积分。讲师用一句话概括其意义：在“没用但可采样”的分布与“想要且有用”的数据分布之间做插值。

具体例子是因子化混合路径：引入调度器 kappa T，从零开始、到一结束；条件路径逐维独立，每个 token 以 1 减 kappa T 的权重保留初始分布、以 kappa T 的权重倾向数据。采样方式是先从伯努利（Bernoulli）分布采样掩码，再按掩码在噪声与数据之间选择，最后拼接成序列。讲师借此对比连续情形：“之前我们某种程度上是在移动质量……现在，我们实际上只是降低一个分布的权重并提高另一个分布的权重。”传输变成了淡入淡出，但除此之外没有区别。

随后是关键的边缘化技巧（marginalization trick）：把边缘速率矩阵定义为对 Z 求和的条件速率矩阵乘以给定 X 时 Z 的后验概率。讲师给出的保证是：用初始分布初始化、按该速率矩阵演化的 CTMC，其 X_T 服从边缘概率路径，因而 X_1 服从数据分布。

证明依赖 Kolmogorov 前向方程（Kolmogorov forward equation），讲师把它类比为连续性方程或 Fokker-Planck 方程在离散设定下的对应物：概率的时间导数等于所有 Y 到 X 的净流入之和。证明路线是：对边缘路径定义求导、交换求和与导数、对条件路径套用 KFE、再交换 Z 与 Y 的求和顺序，最后括号中剩下的正是边缘速率矩阵的定义。讲师自嘲时间紧张、讲得快，并说明这些细节都在讲义里。

## 五、学习即分类：离散流匹配损失

配方只剩下最后一步：学习边缘速率矩阵。讲师先给出具体条件速率矩阵的形式，其规则简单得近乎朴素：如果当前位置已经等于目标 C，速率为零；如果目标 V_I 正是应该去的地方，速率为一乘以因子；如果当前状态是错的，则以负一乘以该因子的速率离开。讲师用一句话翻译：“我从我现在在的地方开始，然后交换到应该在的地方。我对每个 token、序列中的每个位置都这样做。”

那个因子是 kappa 的导数除以 1 减 kappa。讲师特意解释了它为什么会爆炸：在时间一处，如果还不在应在的位置，“我必须确保我在时间一处在那里”，所以速率必须变得非常大，以保证以概率一到达目标。

接着是对边缘速率矩阵的更强陈述：它同样是因子化的，形式与条件版本相同，唯一的区别是把已知的终点 Z 替换为给定 X 时终点取某值的条件概率。讲师在回答提问时点明了证明思路：取凸组合，也就是对后验取期望。

于是整讲的落点出现了：“这个方程中唯一非平凡的东西是这个条件概率……换句话说，它是一个分类器。我们知道怎么做分类。”训练目标就是交叉熵或负对数似然：采样数据点 Z、采样时间 T、从因子化混合路径采样被部分破坏的 X，网络（可以直接是一个 transformer）对每个位置输出 logits，取 softmax，对每个位置做负对数似然并最小化。讲师总结道：“就像 flow matching 最终被证明只是回归一样，离散 flow matching 或离散扩散归根结底也只是分类，只是用不同的方式做而已。”

## 六、掩码扩散与工程权衡

实践中最常见的形态是掩码扩散语言模型：在词表中引入一个原本不存在的 mask token，初始分布恒为“一切都被掩码”。讲师展示了一个名为 Lada 的模型按此方式生成莎士比亚风格文本的过程：模型逐步把 mask token 替换为真实 token，且是非自回归的——“它不只是一味从左到右。它经常是从左到右，但不只有从左到右。”在回答“模型如何决定保留哪些”时，讲师重申这由学到的速率经归一化后的分类分布采样决定。

讲师最后给出了相当克制的优缺点评估。优势方面：并行生成多个 token，可能带来更快速度；可以任意顺序生成；可用于文本编辑场景——比如在一个很大的代码库文件中间掩码需要修改的部分，“你基本上可以固定哪些被掩码、哪些没有被掩码，从而进行条件化”；还可能设计具有语义意义的概率路径。劣势方面：工程挑战，例如 KV 缓存（KV caching）在这个设定下更难做，尽管已有人在研究；需要学会任意顺序生成，可能让学习问题变难；而自回归的从左到右顺序本身带有语义意义——“我没有用这张幻灯片来开始这堂课。那将毫无意义。”讲师明确表示不判断哪个更好，而是让领域和未来决定，并指出对蛋白质序列或 DNA 这类没有自然阅读顺序的数据，顺序约束可能没那么重要。这段讨论也回应了前面的条件化提问：无分类器引导依赖向量相加，而离散空间不能再加向量，因此条件化要另寻路径。

## 七、这一讲在课程路径中的位置

回看整门课的结构，第六讲是一个刻意的收束。前四讲用连续时间工具建立了完整的生成建模流水线：概率路径、向量场、损失函数、引导与潜空间。第六讲只做一件事：证明这条流水线的每一环都能被替换——ODE 换成 CTMC，向量场换成速率矩阵，高斯换成均匀分布，回归换成分类——而配方不变。

讲师在结尾把这一观察提升为更一般的命题：流匹配配方之所以能如此顺利地迁移，是因为它“与 ODE 关系很小，与 CTMC 关系也很小。它与某事物是马尔可夫过程并具有某些性质有关。这是由生成子（generator）指定的”。他把这一更一般的原理称为生成子匹配（generator matching），并说明它可以为一大类马尔可夫过程推导出来。这既是对本讲内容的定位，也是对整门课方法论的一次回望：具体方程只是表层，可迁移的是“用条件路径构造边缘路径、再把边缘化变成可学习目标”的思想。

对学习者而言，这一讲的价值不在于记住速率矩阵的每个下标，而在于看到同一套推导骨架在不同状态空间中的复现能力。讲师自己也说，他用了四节课讲一类模型，今天只有一节，但“很多原理都能非常高效地推广或转换……一旦你看过一种类型，你就能明显更快地学会另一种类型”。

## 结语

MIT 6.S184 第六讲用一节课完成了从连续到离散的跨越：CTMC 取代 SDE，速率矩阵取代向量场，因子分解条件把指数级状态空间压缩为线性可处理的输出，Kolmogorov 前向方程支撑起边缘化技巧，而最终的学习目标收敛为逐位置的分类。掩码扩散语言模型是这一框架最直接的工程化身，它以任意顺序去掩码文本，带来并行生成与编辑式条件化的想象空间，也带来 KV 缓存与顺序语义等未解权衡。作为课程的最后一讲，它没有给出“哪种模型更好”的结论，而是给出了一套可以继续迁移的推导语言。
