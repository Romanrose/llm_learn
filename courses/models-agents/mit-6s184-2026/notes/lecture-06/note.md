## 学习目标

完成本讲后，应能做到：

1. 说清离散扩散模型（discrete diffusion model）与连续扩散模型的对应关系：状态空间从 \(\mathbb{R}^D\) 换成 \(V^D\)，向量场（vector field）换成速率矩阵（rate matrix），ODE 换成连续时间马尔可夫链（continuous time Markov chain, CTMC）。
2. 写出速率矩阵的定义与合法性条件（非负、列和为 0），并用两状态例子验证。
3. 解释因子分解条件（factorization condition）：速率矩阵只在汉明距离为 1 的状态对之间非零，并说明为什么这是让模型可存储、可训练的必要条件。
4. 复述离散流匹配（discrete flow matching）的完整配方：条件/边缘概率路径 → 条件/边缘速率矩阵 → 训练损失，并指出它与连续流匹配逐项对应。
5. 说明离散流匹配最终归结为逐位置分类（classification），损失为负对数似然，模型可以是普通 transformer。
6. 描述掩码扩散语言模型（masked diffusion language model）的采样过程，并诚实地讨论其相对自回归模型的优缺点。

## 核心概念

### 1. 字母表与状态空间

- 字母表（alphabet）/词表 \(V\)：字符集合，大小为 \(V\)。它可以是英文字母、氨基酸集合、字节对编码（BPE）token、词，甚至字节——这是一个抽象数学框架，具体选择在实践中很重要。
- 状态空间 \(S = V^D\)：长度为 \(D\) 的字符序列集合。与之前 \(\mathbb{R}^D\) 的关键区别：状态空间基数为 \(V^D\)，**指数级大**，所有可能的英文句子构成的集合就是指数级的。

### 2. 速率矩阵（rate matrix）

速率矩阵 \(Q_t(Y \mid X, t)\) 接收两个状态和时间，输出非负数。直觉：不能像连续空间那样"朝某个方向移动"（从字母 Y "朝字母 X 的方向"没有意义），唯一能做的事是**切换**，速率矩阵指定切换发生的速率。

两个条件：

- 非负性：\(Q_t(Y \mid X) \ge 0\)。为零意味着不切换；不能比"什么都不做"更少。
- 平衡条件：\(Q_t(X \mid X) = -\sum_{Y \ne X} Q_t(Y \mid X)\)，即留在原地的速率等于所有离开速率之和的负值。按讲师的约定（列索引为 X，对行索引求和），这等价于**列和为 0**。讲师强调这只是约定，取决于你把什么当行、什么当列。

### 3. CTMC 与转移核

CTMC 是无记忆的随机过程，由转移概率（转移核，transition kernel）刻画：
\[
P_t(X_{t+h} = Y \mid X_t = X)
\]
即给定时刻 \(t\) 在 X，稍后 \(t+h\) 在 Y 的概率。速率矩阵与转移核的关系：转移概率在零偏移处对时间的导数由速率矩阵给出——"就像 ODE 指定轨迹，这里速率矩阵指定转移概率如何随时间变化"。

**两状态例子**：状态 A、B，从 A 到 B 的速率为 \(\lambda\)，则由列和为 0，从 A 到 A 的速率为 \(-\lambda\)。对应的转移概率含指数项（讲师板书口述中给出形如 \(1 \pm e^{-2\lambda h}\) 的表达式，并在讲解中当场修正了一次口误）。当 \(h \to \infty\)，指数项趋于零，转移概率趋近 \(1/2\)：系统收敛到两状态上的均匀分布，完全"忘记"初始位置。

### 4. 因子分解条件（factorization condition）

参数化速率矩阵 \(Q_{t,\theta}\) 必须满足：若 Y 与 X 在超过一个位置 \(i\) 上不同（即汉明距离 Hamming distance > 1），则速率为零。换言之，只允许**一次切换一个 token**。

必要性：状态空间指数级大，不施加稀疏性约束就无法存下速率矩阵的一列（更不用说整个矩阵）。有了该条件，网络只需输出形状为 \(D \times V\) 的量——对每个位置 \(j\)、每个词表元素 \(v_i\)，给出从当前 token 切换到该 token 的速率，随维度**线性**增长。

幻灯片对比：左侧是无约束的速率矩阵（每个 X 可到每个 Y）；右侧是因子化后的稀疏结构（只能一步跳到汉明距离 1 的邻居；多次切换仍可在更长时间内到达其他状态，但那些位置的**速率**为零）。

### 5. 从速率矩阵采样

初始分布：连续情形用高斯，但高斯在离散状态空间无定义，因此改用 \(S\) 上的**均匀分布**（每个序列等概率，易于采样）。另定义 delta 函数：\(\delta(Y, X) = 1\) 当且仅当 \(X = Y\)，否则为 0。

采样困难的根源：我们只有速率矩阵的隐式定义，没有转移概率。解法是对 \(h\) 在 0 处做泰勒展开：
\[
P_t(X_{t+h} = Y \mid X_t = X) \approx \delta(Y, X) + h \cdot Q_t(Y \mid X)
\]
其中第一项来自"零时间不移动"的平凡事实，第二项按定义就是速率矩阵。这个近似是关于 Y 的合法分布：delta 求和为 1，速率矩阵对 Y 求和为 0，总和为 1——**这正是速率矩阵平衡条件的用途**。于是可以按类别分布（categorical distribution）直接采样。

采样算法要点：时间从 0 到 1，步长 \(h = 1/N\)；从初始分布采样 \(X_0\)；每步用因子化速率网络算出每个位置 \(j\) 在所有词表元素上的速率，按上述近似构造类别分布并采样更新。实践中各位置可**并行**更新。讲师说明：一阶近似下只需关心单 token 更新；更高阶事件（一个区间内 X→Y→Z 连续跳两次）被忽略，这就是该方法累积误差的来源。

关于条件化（conditioning）：无分类器引导依赖向量相加，离散空间不能加向量，因此不直接适用；但可以把提示作为额外变量传入速率矩阵，或用掩码（mask）方式固定部分位置来实现条件生成。

## 关键公式与原则

### 离散流匹配配方（与连续流匹配逐项对应）

| 连续流匹配 | 离散流匹配 |
|---|---|
| 条件概率路径 \(p_t(X \mid Z)\) | 条件概率路径（概率质量函数，对 X 求和为 1） |
| 边缘概率路径 \(p_t(X) = \int p_t(X \mid Z) p_{data}(Z)\, dZ\) | \(p_t(X) = \sum_{Z} p_t(X \mid Z) p_{data}(Z)\) |
| 条件向量场 | 条件速率矩阵 \(Q_t^Z(Y \mid X)\) |
| 边缘向量场 | 边缘速率矩阵 \(Q_t(Y \mid X)\) |
| 条件流匹配损失 / 边缘流匹配损失 | 条件 / 边缘离散流匹配损失 |

路径端点条件：\(t=0\) 时为 \(p_{init}\)（与数据点无关，已完全遗忘数据）；\(t=1\) 时 \(p_1(X \mid Z) = \delta(X, Z)\)，从而边缘路径在 \(t=1\) 处等于数据分布。

**条件速率矩阵的定义性条件**（与"遵循 ODE 就遵循条件路径"完全平行）：若以 \(p_{init}\) 初始化、且 \(X_t\) 是遵循 \(Q_t^Z\) 的 CTMC，则 \(X_t\) 服从条件概率路径。

**离散边缘化技巧（discrete marginalization trick）**：
\[
Q_t(Y \mid X) = \sum_{Z} Q_t^Z(Y \mid X)\, p_{t \mid 1}(Z \mid X)
\]
即对所有数据点 Z 求和，用后验概率加权。结论：以 \(p_{init}\) 初始化、遵循该边缘速率矩阵的 CTMC，其 \(X_t\) 服从边缘概率路径，特别地 \(X_1 \sim p_{data}\)。

**Kolmogorov 前向方程（证明的核心工具）**：\(X_t\) 服从概率路径 \(p_t\) 当且仅当
\[
\partial_t p_t(X) = \sum_{Y \in S} Q_t(X \mid Y)\, p_t(Y)
\]
这是连续性方程 / Fokker–Planck 方程在离散设定下的类比。右边是**净流入**：X 处概率质量的变化率等于所有 Y 流向 X 的流量之和。证明思路：对边缘路径定义求导 → 交换求和与求导 → 对条件路径套用 KFE → 交换 Z 与 Y 的求和 → 乘除 \(p_t(Y)\) 凑出边缘速率矩阵的定义 → 得到 KFE 成立。讲师明确说这个证明"仅供参考，不构成投资建议"，对通过课程并不重要，细节在讲义中。

### 因子化混合路径（factorized mixture path）

调度器（scheduler）\(\kappa_t\)：满足 \(\kappa_0 = 0\)、\(\kappa_1 = 1\)，淡入数据、淡出噪声（幻灯片中蓝色为 \(\kappa_t\)，橙色为 \(1-\kappa_t\)）。条件路径逐维独立：
\[
p_t(X \mid Z) = \prod_j \left[ (1 - \kappa_t)\, p_{init}(X_j) + \kappa_t\, \delta(X_j, Z_j) \right]
\]
采样方式：对每个位置采伯努利 \(m_j \sim \text{Bernoulli}(\kappa_t)\)，从初始分布采噪声 \(c_j\)，若 \(m_j = 1\) 取 \(Z_j\)，否则取 \(c_j\)，拼接成序列。端点检验：\(t=1\) 时 \(\kappa_1 = 1\)，伯努利总出 1，总取数据；\(t=0\) 时总取噪声——路径性质成立。

讲师强调与连续情形的直观差异：连续流是**传输**（在空间中移动质量），这里是**淡入淡出**（降低一个分布的权重、提高另一个的权重）。"除了这个，没有区别。"

**条件速率矩阵的显式公式**（对每个位置 \(j\)，从 \(x_j\) 切换到词表元素 \(v_i\)）：
- 若 \(x_j = z_j\)（已在正确位置）：速率为 0；
- 若 \(v_i = z_j\)（这是应该去的地方）：速率为 \(\dot\kappa_t / (1 - \kappa_t)\)；
- 若 \(v_i \ne z_j\)（不该去的地方）：速率为 0；
- 离开当前错误状态的速率为该因子的负值（由平衡条件给出）。

因子 \(\dot\kappa_t / (1-\kappa_t)\) 在 \(t \to 1\) 时**爆炸**：因为 \(t=1\) 时必须概率 1 处于正确位置，所以要确保最后一刻完成所有必需的切换。

**边缘速率矩阵的显式公式**：形式与条件版本相同，唯一变化是把已知终点 \(z_j\) 替换为"给定当前 X，终点第 \(j\) 个 token 为 \(v_i\) 的概率"这一后验概率。讲师指出证明就是取凸组合（对后验取期望）：代入定义、只有终点项依赖 Z、用概率替换即可。**关键信息：这个方程中唯一非平凡的东西是条件概率——它就是一个分类器（classifier）。**

### 离散流匹配损失

先学后验网络 \(f_\theta\)：输入部分破坏的序列 X，对每个位置 \(j\) 输出词表上的 logits，softmax 得概率。损失为负对数似然（等价于交叉熵）：
\[
\mathcal{L} = \mathbb{E}_{Z \sim p_{data},\, t \sim U[0,1],\, X \sim p_t(\cdot \mid Z)} \left[ -\sum_j \log f_\theta(X)_j[Z_j] \right]
\]
即"网络认为正确 token 的概率是多少，最大化它"。讲师的原话式总结：**流匹配最终归结为回归；离散流匹配/离散扩散最终归结为分类**，只是在不同位置、不同 token 上摊销地做分类。损失分条件与边缘两种版本，与连续情形最后一列对应。

## 课程作业关联

本讲未直接布置或描述具体作业题。可合理关联的练习方向（均基于讲内明确内容）：

1. **验证速率矩阵合法性**：对两状态例子，检查列和为 0，并验证给出的转移概率满足导数条件。
2. **手推采样近似的归一化**：证明 \(\delta(Y,X) + h Q_t(Y \mid X)\) 对 Y 求和为 1，指出哪一步用到平衡条件。

5. **实现采样循环**：从均匀（或全 mask）初始分布出发，按 \(h = 1/N\) 步长，用因子化速率构造类别分布并并行更新各位置。
6. **思考题**：为什么因子分解条件是"一阶正确"的？更高阶误差从何而来？（讲内问答明确讨论了这点。）

## 常见误区

- **"离散扩散模型就是扩散模型。"** 错。讲师明确澄清：没有 SDE、没有 ODE、没有流；数学对象是 CTMC。被推广的是**学习原理**，不是扩散过程本身。
- **"速率矩阵可以任意参数化。"** 不行。必须满足非负性与列和为 0；且为实用必须满足因子分解条件，否则 \(V^D\) 的状态空间无法存储。
- **"可以直接从速率矩阵定义转移概率并采样。"** 不行。转移概率未知，只能用一阶泰勒近似构造类别分布；这引入忽略高阶跳跃的误差。
- **"无分类器引导可以直接搬到离散情形。"** 不直接适用，因为它依赖向量相加；离散中应使用额外条件变量或掩码固定位置。
- **"初始分布还用高斯。"** 高斯在离散状态空间无定义；用 \(S\) 上的均匀分布（掩码扩散则用全 mask 的退化分布）。
- **"离散流匹配需要新的训练范式。"** 不需要：就是逐位置分类 + 交叉熵/NLL，网络可以是普通 transformer。
- **"并行生成必然更快、全面优于自回归。"** 讲师明确不做此判断：并行是潜在优势，但 KV 缓存等工程技巧更难应用，任意顺序生成的学习问题可能更难；他还指出自回归的从左到右顺序本身携带语义（"我没有用最后一张幻灯片来开始这堂课"），而蛋白质、DNA 等应用没有这种自然顺序。结论是权衡，由领域与具体应用决定。
- **"掩码扩散里模型自己决定保留哪些 token 是某种特殊机制。"** 不是：就是按学到的速率（由条件概率决定）构造类别分布后采样，多数时候分布倾向保持不变，偶尔采样到去掩码。
