## 一、学习目标

完成本讲后，应能：

1. 说清 Flow Matching 要解决的核心问题：在只能访问数据样本、不知道数据密度的设定下，如何训练一个向量场，使 ODE 从高斯噪声出发、在时间 1 到达数据分布。
2. 区分三组对象：**probability path / vector field / flow matching loss**，以及每一组中的 **conditional** 与 **marginal** 版本。
3. 写出高斯概率路径的构造，理解 noise scheduler（α_t、β_t）的作用与端点条件。
4. 理解条件向量场的公式为何是数据点与当前点的线性加权，并能验证它诱导的流确实沿条件概率路径走。
5. 理解边缘向量场是“给定当前位置 X 时条件向量场的后验加权平均”，即条件期望。
6. 说明 Flow Matching Loss 与 Conditional Flow Matching Loss 只差一个与参数无关的常数，因此最小化子与梯度相同。
7. 写出最简线性调度下的训练算法，并解释它为什么是 **simulation-free** 的。
8. 说明推理阶段仍需数值积分 ODE，以及这带来的主要代价。

## 二、课程主线

上一讲建立了“流模型 / 扩散模型”的采样框架：从初始分布（通常是高斯）出发，演化 ODE（向量场由神经网络给出）或 SDE（在 ODE 动力学上注入由扩散系数缩放的布朗运动），从时间 0 模拟到时间 1，终点即生成对象。但那只是一种“声称的目标”，并未说明如何训练。

本讲补上训练算法。主线可以概括为一条构造链：

1. 先对**单个数据点**定义条件概率路径：从已知初始分布出发，终点坍缩到该数据点的 Dirac 分布。
2. 对数据点做边缘化，得到**边缘概率路径**：在高斯噪声与数据分布之间插值。
3. 定义**条件向量场**：使 ODE 沿条件概率路径演化的向量场；对高斯路径可显式写出公式。
4. 定义**边缘向量场**：条件向量场按后验加权的积分；并证明它诱导的流沿边缘概率路径走，因而在时间 1 生成数据分布。
5. 训练目标本应是回归边缘向量场，但它不可计算；于是退而回归条件向量场，得到 **Conditional Flow Matching Loss**。
6. 证明 Flow Matching Loss = Conditional Flow Matching Loss + 与参数无关的常数，因此二者最小化子相同、梯度相同。
7. 代入最简线性调度，得到一个极简算法：采样数据、采样噪声、随机时间、线性插值、回归“数据减噪声”的速度。

课程反复强调：数学推导不短，但最终算法极其简单；并且整个训练过程**从不模拟 ODE**，这是该方法可扩展的关键。

## 三、核心概念

### 1. 生成建模的设定

课程明确：我们不知道数据密度，也不能在任意 z 处求值，只能从数据分布中采样。这与“有未归一化密度、用 MCMC 之类方法”的设定不同。后续所有构造都必须只依赖“能采样”。

### 2. Dirac 分布

采样结果永远是同一个点的“分布”。课程把它当作概率分布来形式化使用，用来表示条件概率路径在时间 1 的终点：所有质量坍缩到一个数据点。

### 3. 条件概率路径（conditional probability path）

记为 p_t(x | z)，依赖时间 t、当前点 x、数据点 z。要求：

- 对每个 t，给定 z 时它是一个真正的概率分布；
- 起点 p_0 是与数据点无关的已知初始分布（几乎总是高斯）；
- 终点 p_1 是 z 处的 Dirac 分布。

课程强调这是**设计选择**：可以选择不同的路径族。逐字稿中的提问也确认：凡是满足端点条件的 α_t、β_t 选择，都给出一个概率路径，因此它是一个族。

### 4. 高斯概率路径

取时间相关系数（noise schedulers）α_t、β_t，满足 α_0 = 0、α_1 = 1、β_0 = 1、β_1 = 0，定义

p_t(x | z) = N(x ; α_t z, β_t² I)

- t = 0：均值为 0、方差为 1，即标准高斯，与 z 无关；
- t = 1：均值为 z、方差为 0，即 Dirac 分布。

课程给出的最简选择是 α_t = t、β_t = 1 − t，但保留一般调度器的自由度。

### 5. 边缘概率路径（marginal probability path）

把数据点随机化：先从数据分布采样 z，再从 p_t(x | z) 采样 x，所得 x 的分布记为 p_t(x)。其密度为

p_t(x) = ∫ p_t(x | z) p_data(z) dz

课程用一个小图模型解释：Z 按数据分布分布，X 以 Z 为条件。可视化上，它把棋盘格玩具分布平滑地插值为高斯噪声与数据分布之间的连续变形。端点性质：p_0 是初始高斯（与 z 无关的信息被丢掉了），p_1 就是数据分布本身。

注意：p_data(z) 不可求值，但可采样；这正是后面仍能训练的原因。

### 6. 条件向量场（conditional vector field）

记为 u_t^target(x | z)，依赖时间、当前点与数据点，是向量场族。要求：从初始高斯出发模拟该 ODE，点随时间的分布沿条件概率路径演化。

对高斯路径，课程断言（并在讲义中给出完整证明）条件向量场是 z 与 x 的线性加权：

u_t^target(x | z) = (α̇_t / α_t) (x − α_t z) / β_t² · β_t² …（课程原话：不必背精确公式，只需记住它是 z 与 x 的、由调度器决定的线性函数/加权和）

课程现场验证的思路：先猜出该向量场的流（flow）的显式形式，对其求导验证满足 ODE；再令初始条件为高斯，利用“高斯的线性变换仍是高斯、均值按线性项偏移、方差按缩放系数平方缩放”，得到 p_t(x | z) 恰为高斯概率路径。课程还指出：能把高斯推成 Dirac 的向量场只是线性的，这是高斯的一个很好的性质。

### 7. 边缘向量场（marginal vector field）

忘掉具体数据点，定义为条件向量场按后验加权的积分：

u_t^target(x) = ∫ u_t^target(x | z) · p_t(z | x) dz

其中 p_t(z | x) 由贝叶斯法则给出，是“给定当前在 x 时，干净数据点 z 的后验”。课程用直觉解释：你站在 x 处，任何数据点都可能把你带到这里；对每个候选数据点取指向它的方向，用“它有多可能是你来源”的信念加权，做加权平均——即给定当前位置时条件向量场的条件期望。课程特别回应提问：不能只用 p_data(z) 做边缘化，那会忽略“你当前在 x”这一关键信息；用后验正是贝叶斯更新。

**核心命题**：从初始高斯出发演化边缘向量场，流沿边缘概率路径前进；特别地，时间 1 的分布是数据分布。课程强调我们真正关心的只是“它能生成数据分布”，中间路径只是构造手段。

课程还讨论了唯一性：满足连续性方程的向量场一般不唯一（零向量场配静态路径是反例；两个解的凸组合仍是解），但我们的边缘向量场是显式构造出来的那一个，所以我们接受这个选择。

### 8. 连续性方程（continuity equation）

证明核心命题的工具：

∂_t p_t(x) = −∇·(p_t(x) u_t(x))

课程给出“会计”式直觉：某点概率质量的时间变化等于流入减流出；流出减流入由“概率 × 向量场”再取负散度刻画；没有概率质量就没有流动。散度定义为向量场各分量偏导数之和。证明路线：把 p_t(x) 的积分表达式代入连续性方程左边，交换积分与导数，利用条件路径满足条件向量场的连续性方程，再把散度移出积分，乘除 p_t(x)，凑出后验加权的边缘向量场公式——这同时也说明边缘向量场的公式正是这样“被构造出来以满足连续性方程”的。课程声明此证明对通过课程不是必需，讲义附录含完整推导。

### 9. Flow Matching Loss

设神经网络 u_t^θ 为参数化向量场。最直接的做法是回归边缘向量场：

L_FM(θ) = E_{t∼Unif, x∼p_t} ‖u_t^θ(x) − u_t^target(x)‖²

其最小化子正是边缘向量场，但目标不可计算（含后验积分与不可求值的 p_data）。

### 10. Conditional Flow Matching Loss

改为回归可计算的条件向量场：

L_CFM(θ) = E_{t∼Unif, z∼p_data, x∼p_t(·|z)} ‖u_t^θ(x) − u_t^target(x | z)‖²

采样流程即：采样时间、采样数据点、按条件路径加噪、回归条件向量场。其最小化子先验上并不显然，但下一命题解决这一点。

### 11. 两个损失的关系

**核心命题**：L_FM(θ) = L_CFM(θ) + C，C 与 θ 无关。

证明思路（课程声明对通过课程非必需）：对两个损失中的平方范数使用二次公式展开；两边相同的项与关于 θ 为常数的项（边缘/条件向量场的平方范数）可直接消去；剩下的中间项是线性的点积项，代入边缘向量场公式即可验证相等。课程现场也回应了“是否应有关于 z 的期望”的提问：可通过直接从边缘路径采样来重写，但为教学清晰保留了两步采样。

两个推论：

- 梯度相同：∇_θ L_FM = ∇_θ L_CFM（常数项梯度为零），因此用 SGD 优化 CFM 即在优化 FM；
- 最小化子相同：最小值数值不同，但达到最小值的参数相同，训练后的网络即边缘向量场。

课程将此视为本讲“最美”的部分：不可计算的目标与可计算的目标只差一个平移，而优化所需的梯度与最小化子都不受影响。

### 12. 最简算法（线性调度）

取 α_t = t、β_t = 1 − t，则 α̇_t = 1、β̇_t = −1。代入后，条件向量场退化为“数据减噪声”的方向，损失变为：

- 采样数据点 z；
- 采样高斯噪声 ε；
- 采样 t ∼ Unif(0,1)；
- 令 x = t z + (1 − t) ε（数据与噪声的线性插值）；
- 回归 u_t^θ(x) 到 (z − ε)。

课程强调：这不是另一个算法，只是把一般公式具体化；实现上就是“加噪、让网络自己推断是哪个数据点导致了该噪声版本、回归速度”，用自动微分和梯度下降即可，训练深度网络的方式没有任何改变。课程提到该损失被 Meta 的 MovieGen 论文明确采用，Stable Diffusion 3 也使用；闭源模型的具体做法课程表示不确定（按原话保留为不确定表述）。

### 13. Simulation-free 与推理代价

训练全程不模拟 ODE：每次迭代只需一次神经网络调用做回归。课程对比：在无模拟训练出现之前，必须展开轨迹、进行很多步 ODE 模拟，代价高昂。这是方法可扩展的关键。

推理阶段仍需按上一讲所学数值积分 ODE；课程给出定性说法“约 100 步”（明确表示并非精确数字）。代价是推理慢、算力开销大；视频张量巨大、需多次网络调用，课程以此解释视频生成服务收费高的现象。训练简单可扩展，代价转移到推理时的迭代计算。

## 四、关键公式与原则（汇总）

- 高斯条件路径：p_t(x | z) = N(α_t z, β_t² I)，α_0=0、α_1=1、β_0=1、β_1=0。
- 边缘路径密度：p_t(x) = ∫ p_t(x|z) p_data(z) dz。
- 条件向量场（高斯情形）：z 与 x 的线性加权，系数由调度器决定；课程不要求背精确形式。
- 边缘向量场：u_t^target(x) = ∫ u_t^target(x|z) p_t(z|x) dz，p_t(z|x) 为后验。
- 连续性方程：∂_t p_t = −∇·(p_t u_t)。
- L_FM = E‖u^θ − u^target‖²；L_CFM = E‖u^θ − u^target(·|z)‖²；L_FM = L_CFM + C。
- 线性调度算法：x = t z + (1−t) ε，回归目标 z − ε。

原则性要点：

1. 条件对象是积木，边缘对象是目标；可计算性在条件侧，正确性由命题桥接。
2. 只用“可采样”的信息，不对密度求值。
3. 训练无模拟，推理需积分。
4. 数学复杂不等于算法复杂；实现上是回归。

## 六、常见误区

1. **把条件概率路径的终点当成“真正生成的目标”。** 条件路径只生成一个已知数据点，课程明确说这本身“没用”；有用的是边缘化后的边缘路径与边缘向量场。
2. **以为边缘化时用先验 p_data(z) 加权就够了。** 课程专门纠正：必须用后验 p_t(z|x)，因为“你当前在 x”是必须纳入的信息；这本质上是贝叶斯更新。
3. **以为满足连续性方程的向量场唯一。** 一般不唯一（零向量场配静态路径、凸组合都是反例）；我们只是显式构造了可用的那一个。
4. **以为训练时要模拟 ODE。** 恰恰相反，训练是 simulation-free 的单步回归；模拟只发生在推理。
5. **以为 CFM 与 FM 是两个不同目标。** 二者只差与参数无关的常数，梯度与最小化子相同。
6. **把“约 100 步”当作精确基准。** 课程原话是定性估计并明确表示不确定精确次数；本笔记不补充精确数值。
7. **把高斯条件向量场的线性性当成普遍结论。** 课程表述为高斯的一个很好的性质，并对其普适性表示不完全确定（按原话保留）。
8. **把调度器当成需要学习的对象。** α_t、β_t 是我们选择的设计选择，不是学出来的。
9. **混淆“生成分布”与“生成单个点”。** 课程的核心命题是时间 1 的分布为数据分布；单个轨迹只是该分布的一次实现。

- **本笔记的解释性组织**：章节划分、误区条目的归纳、复习清单的提问方式、把“条件/边缘”框架概括为“可计算性在条件侧、正确性由命题桥接”。这些是整理方式，不新增课程结论；凡涉及数值、日期、外部链接、硬件规格的内容，输入未给出，本笔记未补充。
