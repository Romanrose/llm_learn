# MIT 6.S184 Lecture 4：Classifier-free Guidance 课程笔记

## 学习目标

学完本讲后，应当能够：

1. 说清「带提示词生成」相对于无条件生成的建模差异：数据从单变量分布变为成对分布 $(x, y)$，网络多一个提示词输入。
2. 写出朴素引导（vanilla guidance）的训练目标与采样流程，并解释它为什么在理论上「应该够用」。
3. 用贝叶斯法则从条件 score 推导出引导向量场的分解式，理解其中哪一项对应「分类器」。
4. 说明 classifier guidance 的做法、代价，以及它为什么被 classifier-free guidance（CFG）取代。
5. 写出 CFG 的向量场表达式，说明 empty token / label dropout 如何让单个网络同时承担条件与无条件两种角色。
6. 明确 CFG 是启发式方法：它不再严格从数据分布采样，而是以多样性换取提示词对齐。

---

## 课程主线

本讲的逻辑是一条「推导链」，而不是若干独立技巧的罗列：

**朴素引导 → 观察到对齐不足 → 用贝叶斯法则把引导向量场拆成「无条件部分 + 分类器梯度」→ 直接放大分类器项（classifier guidance，需要额外训练分类器）→ 把分类器项改写为两个 score 之差（不再需要分类器）→ 用 label dropout 把两个向量场合并进一个网络（CFG）→ 讨论其启发式本质与代价。**

每一步都只改动上一步的一小部分，这是本讲最值得注意的结构。讲义反复强调：从朴素引导到 CFG，训练流程的改动「非常小」，几乎是免费的摊销（amortization）。

## 核心概念

### 1. 引导（guidance）要解决的问题

课程用「柯基犬」的例子给出经验事实：一个在 ImageNet 上训练的条件模型，即使理论上应当从 $p_t(x\mid y)$ 采样，实际生成的图像「有点狗的风格，但不是我们想要的」。也就是说，**条件向量场没有足够紧密地遵循提示词**。引导的目标就是强化提示词的约束力。

课程此处明确区分了两个术语：
- **unguided**：不指定提示词，随便生成；
- **guided**：按特定提示词生成。

### 2. 朴素引导（vanilla guidance）

做法上「几乎什么都没变」：

- 数据分布变为成对样本 $(x, y)$，采样时遍历「互联网上的图像和提示词」；
- 网络 $u_t^\theta(x)$ 增加一个提示词输入，成为条件向量场；
- 损失函数形式不变，只是回归目标换成条件向量场；
- 采样时选一个提示词，模拟 ODE，每一步都把提示词喂给网络。

课堂上有提问：能否让加噪调度本身依赖提示词？讲者的回答是原则上可以（「那更像是符号上的重载」），但实践中人们不这么做，文献中是否有相关工作也不确定。这是课程明确留下的开放点，不要把它当成已解决问题的结论。

### 3. Classifier guidance：从贝叶斯法则到「放大分类器」

对含噪图像 $x$ 与提示词 $y$ 应用贝叶斯法则并取对数：

$$\log p_t(x\mid y) = \log p_t(y\mid x) + \log p_t(x) - \log p_t(y)$$

对 $x$ 取梯度。$\log p_t(y)$ 与 $x$ 无关，梯度为零；$\log p_t(y\mid x)$ 的梯度正是「给定 $x$ 时 $y$ 的分类器」的梯度。于是得到课程反复使用的分解：

$$\nabla_x \log p_t(x\mid y) = \nabla_x \log p_t(y\mid x) + \nabla_x \log p_t(x)$$

再用 score 与边缘向量场的转换公式（讲者称系数为 $A_t$、$B_t$，并说明「我甚至不用去回忆公式，它就是一个我们已知的系数」），把上式翻译成向量场语言：

$$u_t^{\text{guided}}(x\mid y) = u_t^{\text{unguided}}(x) + A_t \cdot \nabla_x \log p_t(y\mid x)$$

即：**引导向量场 = 不依赖提示词的无条件向量场 + 一个可解释为分类器梯度的提示词相关项**。

Classifier guidance 的定义就是给第二项乘上权重 $w$（讲者口述为 $W$）加以放大。$w=1$ 时退化为原始条件向量场。

课程点明了它的两个代价：
- 需要**额外训练一个分类器**，工作量翻倍，且必须维护两个模型；
- 分类器的输入是**带噪数据** $x$，不能直接用现成分类器；
- 若 $y$ 是长文本而非类别标签，该似然及其梯度都可能极难计算。

### 4. Classifier-free guidance：把分类器消掉

关键一步是把分类器项用同一套贝叶斯关系反解出来：

$$\nabla_x \log p_t(y\mid x) = \nabla_x \log p_t(x\mid y) - \nabla_x \log p_t(x)$$

代回并整理后，引导向量场可以写成两个向量场的加权组合（讲者最终重写为更清楚的形式）：

$$u_t^{\text{CFG}}(x\mid y) = u_t^{\text{unguided}}(x) + w\left(u_t^{\text{guided}}(x\mid y) - u_t^{\text{unguided}}(x)\right)$$

其中 $w \ge 1$。$w=1$ 时差值项消失，退化为普通条件向量场；$w>1$ 时**放大差值**——直观上等价于放大那个假想的分类器，但整个表达式里「不再有分类器了」。

这就是名字的由来：分类器完全是假设性的，理论上我们计算的差值应对应于它，但它从未被训练过。讲者的原话大意是：**我们强化了分类器的效果，却从未训练过分类器**。

### 5. Empty token 与 label dropout

上述公式仍涉及两个向量场，看起来像两个模型。最后一步是把它们合并进**一个网络**：

- 定义一个额外的 **empty token**，告诉模型「我没有在告诉你提示词」；
- 训练时以概率 $P$ **丢掉标签**（label dropout），讲者举例约 20% 的时间不告诉模型提示词；
- 于是同一个网络既能算条件向量场，也能算无条件向量场，CFG 向量场可在一次流程中全部摊销。

课程强调这是对已有训练流程的「最小改动」，也正是 CFG 可扩展的原因：一个网络、一次训练，而不是两个模型。

采样时只需把普通引导中的向量场替换为 CFG 向量场，其余 ODE 模拟流程不变。

## 关键公式与原则

**（1）条件 score 的分解**

$$\nabla_x \log p_t(x\mid y) = \nabla_x \log p_t(x) + \nabla_x \log p_t(y\mid x)$$

原则：条件信息可以写成「无条件 score + 分类器梯度」。

**（2）向量场形式的引导**

$$u_t^{\text{guided}} = u_t^{\text{unguided}} + A_t \cdot \nabla_x \log p_t(y\mid x)$$

原则：score 与向量场之间只差已知系数，因此所有 score 层面的推导都能直接搬进 flow model 的语言。

**（3）CFG 向量场**

$$u_t^{\text{CFG}} = u_t^{\text{unguided}} + w\left(u_t^{\text{conditional}} - u_t^{\text{unguided}}\right),\quad w \ge 1$$

原则：引导强度 $w$ 是**乘在差值上**的。课堂提问中讲者特别澄清：若 $w=4$，「把这项贡献放大了三倍」，因为增量是 $w-1=3$。

**（4）CFG 是启发式，不是精确采样**

这是本讲最重要的原则性警告。讲者明确说：如果训练完美、分布完美，理论上根本不需要 CFG；它是**启发式方法（heuristic）**，其合理性主要来自实验结果。可把它理解为把样本**推向分布的众数（modes）**、推向真正定义某个条件的区域。后果是：
- 首次「超越了数据分布」——现代模型的文本-图像对齐度可能优于互联网上带错误 caption 的随机数据对；
- 但同时也**不再从同一分布采样**，损失多样性。

课程把这一点与全课的理论假设联系起来：整门课都把「从数据分布采样」当作良好的建模假设，而 CFG 提醒我们它是一个近似。

**（5）两类失效模式**

- $w<1$：弱化提示词，模型对提示词的依赖减少；
- $w$ 过大：图像过度饱和，变化消失、坍缩到模态上，只剩「一个像猫的东西」。

**（6）效率代价**

CFG 每步需要**调用两次网络**（一次条件、一次无条件），效率减半。讲者说「没关系，我们能够应对」，但这是必须记住的成本。

## 常见误区

1. **把 CFG 当成「有分类器但不用训练」的精确方法。** 课程明确说它是启发式，理论上不必要，其地位由实验结果支撑。
2. **混淆 $w$ 的语义。** $w$ 乘在差值上，不是乘在条件向量场上；$w=4$ 意味着增量放大 3 倍，$w=1$ 意味着完全没有引导。
3. **认为 classifier guidance 只是「多训一个模型」这么简单。** 分类器必须处理带噪输入；当 $y$ 是长文本时，似然与梯度的可计算性本身就是问题。
4. **以为 label dropout 是可选的工程技巧。** 它是 CFG 成立的前提：没有它，同一个网络无法扮演无条件角色，公式里的 $u_t^{\text{unguided}}$ 就无从计算。
5. **把「对齐更好」直接等同于「模型更好」。** 课程指出对齐提升的代价是偏离数据分布、损失多样性；这是权衡，不是纯粹改进。
6. **以为可以让加噪调度依赖提示词是课程给出的方案。** 课堂上这只是被讨论的可能性，讲者明确说实践中不这么做。
