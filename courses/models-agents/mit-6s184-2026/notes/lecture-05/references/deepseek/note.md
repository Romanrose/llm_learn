## 三、核心概念

### 1. 为什么像素空间不够

课程原意：以 3×600×1000 的图像为例，维度约为 180 万。直接在如此高维空间建模有三重困难：

- **显存/算力**：网络要处理极高维输入，GPU 内存吃紧。
- **学习难度**：要在极高维空间学习向量场。
- **冗余**：相邻像素高度相关，大量细粒度细节可从上下文补全，语义上真正有意义的内容只占一小部分。

讲者特别指出，监督学习（如 ImageNet 分类）不因高维而同等受困，原因有二：其一，扩散/流模型在采样时要反复调用网络（讲者提到约 50–100 次），代价被放大；其二，任务是**向量到同维向量**的映射（180 万维到 180 万维），而非向量到类别。因此需要先把数据变换到低维空间。

### 2. Autoencoder 与重构损失

定义：数据空间 R^D，潜空间 R^K，且 K < D。编码器 μ_φ: R^D → R^K，解码器: R^K → R^D。训练目标是重构损失：

L_recon(θ, φ) = E_{x∼data} ‖ x − decoder_θ(encoder_φ(x)) ‖²

即采样数据点、编码、解码、与原始点比较取均方误差。课程原意：只要 K < D 就构成压缩；重构质量是经验性问题，取决于数据分布。

**关键警告（课程原意）**：仅用确定性 autoencoder，潜分布由「采样 x 再编码」诱导，其形状不受控制，可能非常崎岖、散乱。下一步要在该分布上训练扩散模型，这会把学习问题显著变难。因此需要 VAE。

### 3. VAE：从确定性到随机编码

课程原意：把编码改成分布。编码器给出

q_φ(z | x) = N(z; μ_φ(x), σ_φ²(x))

解码器给出 p_θ(x | z) = N(x; μ_θ(z), σ²)，其中解码方差通常固定（讲者说明原则上可可变，但所关心的情况下固定即可）。编码即从 q_φ(·|x) 采样，同一 x 可有多个编码。

**重构项（概率版）**：最大化 p_θ(x|z) 的对数似然，等价于最小化负对数似然。课程原意：高斯负对数似然就是均方误差，因此这一项与普通 autoencoder 的重构损失形式一致，唯一区别是编码是随机的。

**先验项**：希望潜分布接近标准高斯（讲者称「最好的分布是高斯」：单峰、负对数似然凸、好学好建模）。用 KL 散度度量：

L_prior = E_{x∼data} KL( q_φ(z|x) ‖ N(0, I) )

两个高斯的 KL 公式（讲者板书，含 K(·) 函数）：

KL = ½ Σ_k [ K(σ_q²/σ_p²) + (μ_q − μ_p)²/σ_p² ]

其中 K 函数在比值 1 处取最小值、向两侧趋于无穷，直观上同时惩罚均值偏移与方差偏离。代入 q_φ 与标准高斯，得到：

L_prior = ½ Σ [ σ_φ²(x) + μ_φ²(x) − 1 − log σ_φ²(x) ]（讲者口述形式为「K(σ_φ²) + μ_φ²」，并强调最小化会迫使 σ_φ²→1、μ_φ→0）

**总损失**：L_VAE = L_recon + β · L_prior，β ≥ 0。

**课程原意中的坦诚之处**：单独最小化先验项会得到「μ_φ≡0、σ_φ≡1」的平凡解，完全忽略数据、丧失重构能力；这正是必须把两项加权结合的原因。但 β 如何选、潜分布「多好」才算好，讲者明确表示没有令人满意的通用答案：唯一可靠的检验是在自编码器上训练扩散模型，而这一步很贵。β 通常取得相当小；实践中还有截断 KL 等工程技巧，讲者称其「不那么有原则、因模型而异」。也有听众问及 mode collapse，讲者确认这是 VAE 已知现象，权衡两项可缓解但不根治。

### 4. Reparameterization trick

课程原意（重点）：损失中出现 E_{z∼q_φ(·|x)}[·]，其中采样分布依赖 φ。若直接「采样 z 再对损失求梯度」，采样点本身随 φ 变化，得到的不是该损失的蒙特卡洛梯度估计，数学上不成立——计算可行，但不会最小化目标。这不是反向传播做不到，而是表达式本身不允许这样做。

解决办法：利用高斯性质重写采样

z = μ_φ(x) + σ_φ(x) ⊙ ε,  ε ∼ N(0, I)

于是期望所关于的分布不再依赖 φ，梯度可穿过 μ_φ、σ_φ 反向传播。讲者强调这是「几乎零成本的改写」，应当采用，并顺带对比强化学习中的 REINFORCE：那里策略分布依赖参数、无法直接反传，是同类问题。

**训练算法（课程原意）**：给定数据集、编码器/解码器网络、潜维度 K、常数 β、解码方差 σ²；每个 minibatch：算均值与方差 → 采样噪声 → 重参数化 → 解码 → 算重构损失（缩放平方误差）→ 算 KL 项 → 反传更新。讲者提醒注意 K 与 D 在板书中的笔误。

### 5. Latent diffusion 配方

课程原意：遍历训练图像，用 VAE 编码（讲者提到可简单地取均值）得到潜变量数据集；在该数据集上训练扩散/流模型；采样得到潜变量后，过解码器得到图像。流程与之前完全相同，只是建模对象从图像变成有抽象含义的潜变量。

关于信息损失：讲者承认有损，但实际编解码差异几乎不可察觉，对生成目的通常无碍；并强调如今自编码器设计本身已成为 latent diffusion 成败的关键，有团队专门做自编码器。讲者还指出，网上可见的图像/视频大多是在潜空间中生成再解码的（对闭源情况不作断言）。

### 6. 网络架构：从向量场到 DiT

网络要学的是依赖时间 t、噪声状态 x（潜表示）与提示 y 的向量场，输出与 x 同形状。逐组件：

- **时间**：一维变量，用正弦嵌入（sinusoidal embeddings）提升到 d 维——取一组频率 w_i，计算 cos(w_i t)、sin(w_i t)。
- **文本**：用预训练模型（CLIP、T5、LLM 嵌入等）把提示变成向量序列，长度 s、维度 k，因模型而异。
- **图像**：按 patch 切分并展平为向量序列（vision transformer 思路）。讲者提醒：即使已是潜表示，仍保持通道×高×宽的形状，因此同样 patchify。
- **DiT 块**：对序列做迭代变换。先用 self-attention 处理图像 token（query/key/value 均来自图像）；再用 cross-attention 引入文本（query 来自图像，key/value 来自文本）；时间通过 adaptive layer normalization 注入（归一化后的缩放与偏移依赖时间）。讲者说明存在大量变体，这里只给一种标准设计。
- **输出**：unpatchify 回图像形状。

讲者立场：只有亲手实现才算理解，强烈建议完成 Lab 3；Transformer 细节超出本课范围，讲义有文字补充。

### 7. 案例研究

- **Stable Diffusion 3**：流匹配，α_t = t、β_t = 1−t（第二讲的直线调度器）；classifier-free guidance，训练时约 20% 概率丢弃提示；VAE 潜空间（比课堂概述的更复杂，但核心原则相同：重构损失 + VAE 损失，目标是良好潜分布）；约 80 亿参数；采样约 50 步即约 50 次大网络查询；数据为 LAION 一类清洗过的互联网图文数据；架构为 DiT（讲者提到其对 cross-attention 的使用有变体，文本序列在网络中持续参与）。讲者强调还有巨大的系统工程组件。
- **Movie Gen（Meta）**：同样流匹配 + CFG + 潜空间；视频多出时间轴，张量巨大，自编码器设计尤其关键；朴素设定下时间作为张量另一维一次性生成，也存在自回归展开等做法；patch 从 2D 变 3D（时间+空间）；讲者提到约 300 亿参数、6000 块 H100 训练（训练时长讲者记不清，建议查论文）；一致性、长视频等是公开挑战。

### 8. 文献约定速览（课程原意）

- 时间约定：本课数据在 1、噪声在 0；原始扩散论文相反（数据 0、噪声无穷）。
- 存在离散时间表述，不依赖微分方程，损失经近似导出，最终形式相似。
- 破坏数据的方式：概率路径、随机插值、前向扩散过程，在高斯设定下很大程度上等价。
- 经典 SDE 叙事：前向过程破坏数据 → 时间反转依赖 score function → 学 score；而 score function 是向量场的重参数化，高斯设定下所学对象一致。
- 讲者自陈偏好 flow matching 框架：最简单、只需谈 flows、允许任意分布到任意分布（初始分布不必是高斯，例如部分加噪的图像也可作为起点）。

## 四、关键公式与原则

1. 潜空间维度：K < D；重构损失 L_recon = E‖x − D(E(x))‖²。
2. VAE 编码 q_φ(z|x) = N(μ_φ(x), σ_φ²(x))；解码 p_θ(x|z) = N(μ_θ(z), σ²)。
3. 高斯负对数似然 ↔ 均方误差。
4. L_prior = E_x KL(q_φ(z|x) ‖ N(0,I))；两高斯 KL = ½Σ[K(σ_q²/σ_p²) + (μ_q−μ_p)²/σ_p²]。
5. L_VAE = L_recon + β·L_prior。
6. 重参数化：z = μ_φ(x) + σ_φ(x)⊙ε，ε∼N(0,I)；使期望分布与 φ 无关，梯度有效。
7. DiT 输入：sinusoidal time embedding + 文本嵌入序列 + patch 序列；输出 unpatchify 回原形状。
8. CFG 训练需按概率丢弃提示（经验值约 20%）；丢弃概率过高或过低都会使 CFG 的某一项估计不准，中间值较优（讲者以定性方式说明）。

## 六、常见误区

1. **「有 autoencoder 就够了」**：确定性编码诱导的潜分布可能极难学习；VAE 的先验项正是为此。
2. **「先验项越强越好」**：单独最小化先验项有平凡解（μ≡0、σ≡1），会摧毁重构；必须与重构项加权。
3. **「直接采样再反传就行」**：采样分布依赖 φ 时，该操作在数学上不成立，不是实现细节问题。
4. **「重参数化是近似」**：它是精确的分布改写，无额外损失，且高效。
5. **「潜空间没有信息损失」**：有损，只是对生成目的通常可接受；自编码器质量因此至关重要。
6. **「潜表示不需要 patchify」**：潜表示仍是通道×高×宽形状，patch 化照旧；视频则需 3D patch。
7. **「不同扩散论文的公式不同，所以模型不同」**：时间约定、离散/连续、概率路径/前向过程多为同一思想的不同表述，高斯设定下很大程度上等价。
