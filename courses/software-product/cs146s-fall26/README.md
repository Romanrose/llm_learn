# Stanford CS146S · The Modern Software Developer · Fall 2026

通过 Coding Agent 的内部机制、上下文工程、MCP、Skills、仓库规范、代码审查、安全和后台智能体，学习组织可靠的软件开发流程。讲师：Mihail Eric。先修要求：相当于 CS111 / CS161 的编程经验，推荐 CS221 / CS229 背景。
