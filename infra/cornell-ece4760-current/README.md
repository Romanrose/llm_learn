## 硬件与学习方式

课程当前主页使用 Raspberry Pi Pico 2 / RP2350。实物练习所需元件依官方 bill of materials 和各 Lab 清单。该课教授嵌入式基础，并非专门的 AI 模型训练课。课程演示仓库含 RP2040 历史示例，使用 Pico 2 时需核对芯片、SDK 与引脚。

官方列出的 2022、2025 历史录像不绑定成当前课程各单元录像。
