## 课程主线

本讲的目标是建立对现代语言模型架构的“经验性共识”的整体认知。核心方法不是从理论推导出发，而是通过系统地回顾近年发布的各类模型（GPT、Llama、Gemma、Qwen、OLMo 等），归纳出所有有效架构共享的固定参数与选择，以及可以灵活调节而不会显著影响性能的部分。

讲义的推进顺序：

1. **LayerNorm** 的放置位置与变体选择。
2. **激活函数** 的门控化改造。
3. **并行层 vs. 串行层** 的取舍。
4. **位置编码**：RoPE 的动机与实现。
5. **关键超参数**：前馈维度、头维度、长宽比、词表大小的经验法则。
6. **正则化在 LLM 训练中的反直觉行为**。
7. **训练稳定性技巧**：z-loss、QK-norm、logit softcapping。
8. **推理效率干预**：MQA / GQA、滑动窗口注意力。

贯穿全讲的核心理念是：**架构是一组复杂的权衡**——必须在表达能力（泛化）、GPU 训练效率、推理成本、训练稳定性之间取得平衡。许多看似随意的设计选择，实际上是这几方面压力共同作用的结果。

## 核心概念详解

### 1. 归一化：LayerNorm → RMSNorm，pre-norm → post-norm

#### 残差流原则

Transformer 中存在一条贯穿网络的残差流（residual stream），注意力与 FFN 以增量（delta）形式向残差流添加信息。原始 Transformer（Vaswani et al., 2017）将 LayerNorm 放置在残差流内、每个子层末尾，这一做法被称为 **post-norm** 或 **residual norm**。

所有现代 LLM 都放弃了这一做法，转而采用 **pre-norm**：将 LayerNorm 移动到残差流之外、每个子层计算之前。

**为什么？**

- **梯度衰减问题**：post-norm 意味着每经过一个 Transformer 块，梯度都要经过 LayerNorm 的缩放，梯度范数会逐层改变；pre-norm 则为反向传播提供了“直通”路径，梯度可以无阻碍地从输出传播到输入。实验（Salazar & Nguyen）显示 pre-norm 显著减少了梯度尖峰的大小和频率。
- **训练稳定性**：pre-norm 允许更深的网络稳定训练，部分研究的最初动机是消除 warmup 的需求（尽管现代训练仍需要 warmup）。

#### 归一化变体

- **LayerNorm**：减去均值、除以方差、再重新缩放。表达能力更强。
- **RMSNorm**：只做缩放，不减均值、不加偏置。表达能力略弱，但在实践中无显著性能差异；系统效率显著更高——LayerNorm/RMSNorm 这类归一化操作虽然仅占总 FLOPs 的约 0.17%，但因其低算术强度（memory-bound），在小模型上可能占据高达 25% 的运行时间。RMSNorm 已成为几乎所有现代模型的标准选择。

**Grok、Gemma 2、OLMo 2** 等模型在两个子层计算结束后放置归一化（仍是 pre-norm 逻辑，但位置在计算之后）。另有一些模型采取 **double norm**——在计算前后各放一个归一化。

**经验法则**：遇到稳定性问题时，“在各处撒上 LayerNorm”通常能改善稳定性（例如单独在注意力计算内部添加一个 LayerNorm），这一做法在多个模型中被反复验证有效。

**偏置项**：原始 Transformer 的所有线性层都带偏置，但大多数现代实现直接省略偏置。偏置项同样是低算术强度、高内存密度的操作，去掉偏置不损失表达能力，同时提升系统效率。

### 2. 激活函数：门控线性单元（GLU）

#### 从 ReLU 到 GeGLU / SwiGLU

- 原始 Transformer 使用 **ReLU**。
- GPT-3 改用 **GeLU**（高斯误差线性单元），与 ReLU 的差异仅在接近零处的梯度形状与底部的一个小凹陷。
- 真正的性能跳跃来自 **GLU（Gated Linear Unit，门控线性单元）** 家族。

**SwiGLU / GeGLU 结构（以 SwiGLU 为例）**：

- 标准 MLP：输出 = W₂·ReLU(W₁·x)
- GLU 变体：输出 = W₂·(Activation(W₁·x) ⊙ (V·x))

其中 **V** 是一个额外的门控矩阵，V·x 对激活输出逐元素相乘做门控。命名规则：前置激活函数名 + GLU。ReLU + GLU = ReGLU，GeLU + GLU = GeGLU，Swish(x)·x = SwiGLU。

#### 关键细节：参数匹配

GLU 比普通 MLP 多一个矩阵 V，直接替换会增加约 50% 参数。标准做法（由 Noam Shazeer 提出）是：**将前馈维度缩小约 2/3**，以保持总参数数量不变。此后的实验比较（在参数匹配前提下）显示 GLU 变体几乎总是优于非 GLU 变体，且计算开销增加很小。

- Google 系模型（Gemma、T5）偏好 GeGLU。
- Llama 系及其后继者偏好 SwiGLU。

非 GLU 模型的例外（如 Nemotron 340B 使用 Squared ReLU）极其少见，且并非刻意推荐。**结论：GLU 是“免费的胜利”。**

#### 并行层 vs. 串行层

串行形式：先注意力，后 MLP，逐个计算。并行形式（GPT-J 首创、PaLM 采纳）：将注意力和 MLP 的贡献同时加回残差流，可共享 LayerNorm 与融合矩阵乘法，提升系统利用率约 15%，但会损失“一半深度”。现代主流模型已回到串行形式——串行优化的成熟使得并行带来的系统优势不值得表达能力的代价。

### 3. 位置编码与 RoPE

#### 问题背景

注意力机制是位置无关的（permutation invariant）。没有位置编码，打乱输入顺序不影响输出。原始 Transformer 引入了正弦/余弦绝对位置嵌入。

#### RoPE：旋转位置编码

**核心思想**：在二维空间中，将每个单词的嵌入向量根据其绝对位置旋转相应角度。由于“内积对旋转不变”，任意两个位置旋转后的向量的内积仅取决于它们的相对角度差——这实现了“相对位置”的约束：f(xᵢ, i) · f(xⱼ, j) = g(i-j)。

**关键点**：这个性质要求位置编码能被分解为关于词向量和位置的乘积形式，而旧方法不满足——正弦嵌入存在绝对位置的交叉项，绝对位置嵌入显然非相对，相对位置嵌入（如 T5 风格）只能加到注意力矩阵上，无法分解为两个向量的内积。

**高维实现**：将 D 维向量切成两两一组的分块，每组做二维旋转，对应不同的角度频率。低频旋转慢，捕捉长距离依赖；高频旋转快，捕捉局部邻近关系。

**实现细节**：

- 根据序列位置生成余弦和正弦角度表（通常为每层共享）。
- 将旋转应用于 Query 与 Key 向量，而非直接加到嵌入上。
- 每次注意力计算前都要应用，以确保位置不变性成立。
- 实现方式：等价的复数乘法或稀疏矩阵旋转，也可直接手工实现。

**RoPE 成为绝对主流**：2024 年之后的几乎所有模型均采用 RoPE。Gemma 4 有一种变体 p-RoPE，只旋转前两个坐标来节省显存（面向小模型）。还有一些模型（如若干混合架构中的局部层）使用 NoPE（No Positional Embedding），完全去掉位置嵌入。

### 4. 关键超参数：经验法则与合理取值范围

#### 前馈维度比例（ff_dim / model_dim = ratio）

- 经验法则：非 GLU 模型约 **4 倍**。
- GLU 变体在 2/3 缩小后约为 **2.67**。
- Llama 2 选择 **约 3.5**（理由：MQA 带来了效率，可给 MLP 更多参数预算）。
- T5 是极端例外：64 倍，基于系统效率考虑（更大的矩阵乘法硬件利用率更高）；但 T5 v1.1 又回到了 2.5 倍，暗示极端选择虽可行但计算效率不佳。

**经验结论**：这是一个**宽容度极高**的超参数。小规模扫描（Kaplan et al., 2020）显示约 1–10 之间都有一个性能平坦的盆地，在这个范围内选择几乎不影响损失。

#### 头维度（head_dim）

- 经验法则：使得总维度不变——即 head_dim ≈ model_dim / num_heads。
- 几乎所有模型都遵循这一准则；显著例外是 T5 和 Lambda 系列。
- 与 ff_dim 类似，head_dim 在 1 附近有一个很宽的平坦盆地，是最不敏感的超参数之一。

#### 长宽比（模型宽度 / 深度）

- 大多数模型的 model_dim ≈ 100 × num_layers（约 100 倍比例）。
- 深层模型难以做张量并行，薄而深需要流水线并行（所有人都不愿意碰）；浅而宽则更易并行。系统与表达能力的权衡最终收敛到约 100。

#### 词表大小

- 单语英语模型：约 30k。
- Llama 系及现代多语言/生产系统：约 100k–200k。
- 驱动因素：多语言覆盖范围与模型规模（较大模型能更好地支撑大词表）。若模型包含视觉等非文本模态，tokenizer 需额外的大词表。

#### 正则化：一个反直觉的结论

直觉推理：语言模型数据多、单次遍历训练、几乎不可能过拟合，因此 dropout 或 weight decay 可能不需要。**但实验数据显示 weight decay 仍然被许多现代高性能模型使用**，原因并不是正则化，而是它和优化器/学习率衰减交互，帮助收敛到更好的极小值——本质是**优化干预，而非正则化干预**。dropout 则已基本淡出主流。

### 5. 训练稳定性：三大技巧

#### 输出端：z-loss

Softmax 计算中的归一化项 log z 可能爆炸（指数运算）或崩溃。技巧：在损失中加入惩罚项，使 log z 朝向 0。来自 Jacob Devlin 的论文（2014 年）。Baichuan 是最早采用的开源模型，DCLM、OLMo 等随后跟上。

#### 注意力端：QK-norm

在 Q 与 K 点积之前对它们分别做层归一化或 RMSNorm，使 softmax 输入的尺度大致恒定（尺度保持为 1）。源于多模态模型（Idefics、Chameleon）。**不会影响性能**，但有效防止注意力退化与梯度尖峰——如今已成为大多数 LLM 的标准配置。

#### 强行限制：Logit Softcapping

直接对注意力 logits（进入 softmax 的原始值）施加 Tanh 软上限（如 ±30），硬性防止极端 logits。Gemma 2/3/4 使用。**注意代价**：作为强干预手段，会损失表达能力与性能表现，只适合作为稳定性优先的策略。

### 6. 推理成本与 KV 缓存：MQA 与 GQA

#### 推理的场景

自回归生成只能逐个 token 生成。为不重复计算历史内容，需要维护 **KV 缓存**——存储过去所有 query-key 交互。问题在于生成阶段算术强度很差：内存访问中，序列长度项变为 n²（必须反复读取整个 KV 缓存）。

#### MQA（Multi-Query Attention）

所有注意力头共享同一组 K 和 V，只有 Query 不同。KV 缓存大幅缩小，算术强度中的关键项从 n/d 变为 h·(n/d)（h 为注意力头数）。代价：表达能力显著下降。

#### GQA（Grouped-Query Attention）

将头的集合分成若干组，组内共享同一组 K 和 V，组间独立。你可以通过分组数在表达能力和效率之间连续调节。实验显示，分组数只要不要太少（即 KV 头数不要太小），推理成本大幅下降的同时，性能损失几乎可以忽略。这解释了如今几乎所有模型（包括 Llama 3、Qwen 系列、Gemma）都倾向于 GQA 而非完整 MHA 或 MQA。

### 7. 长上下文：滑动窗口注意力与混合架构

- GPT-3 原始论文就有在全局注意力与带状矩阵（带状滑动窗口）间交替的设计。这想法最近重新流行。
- 示例结构（Command A）：每 4 层有 1 层全局全注意力 + 3 层滑动窗口局部注意力。局部层自底向上聚合信息，最终仍可获得全局感受野。
- 更激进的变体：局部层用 NoPE，彻底消除全局位置信息，在滑动窗口外退化为“词袋”。
- 采用者：Cohere Command A→ 随后有 Llama 4、Gemma 4、OLMo 3（用完整 RoPE + 滑动窗口）；Qwen 3.5 在每四层间交替使用状态空间模型门控 Delta 网络与全局注意力层。
- 核心论点：**纯全局注意力的成本不再可行，纯局部注意力无法捕捉长期依赖。混合模型已成为处理长上下文的主流方案。**

## 常见误区

1. **认为 LayerNorm 只能放在子层之前**：事实：可以放在计算后（post-norm 但仍在残差流外），甚至 double norm。关键是**不要放在残差流内**。
2. **认为 GLU 一定优于非 GLU**：在相同参数预算前提下，实验数据显示 GLU 更优；但直接替换不缩小维度会带来参数量的非线性增长，且并非绝对。
3. **认为 RoPE 是正弦位置嵌入的变体**：RoPE 是乘法（旋转），不是加法（嵌入）。它没有交叉项，因此严格满足相对位置约束。
4. **认为 head_dim 必须等于 model_dim / num_heads**：这只是经验法则，并非硬性要求；该超参数宽容度很高。
5. **认为 weight decay 的唯一作用是正则化**：在单次遍历 + 大数据条件下，它可以表现为优化器的隐式偏置，通过与学习率衰减的交互改善收敛。因此它依然被现代模型使用。
6. **认为 QK-norm 一定会损失表达能力**：多数实验显示它不影响性能，但 logit softcapping 这类强干预通常会使性能下降。
7. **认为滑动窗口会丢失长期依赖**：混合架构以层为粒度的交替，使得局部信息可以向上聚合并与全局信息结合，并不是简单的窗口截断。
