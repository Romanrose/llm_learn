# 关于 llm_learn

llm_learn 是以课程为主线的个人学习资料库，围绕编程与计算机系统、大模型与智能体、软件与产品开发三个方向持续整理。

## 如何阅读

从[课程](/)选择一门课，进入课程介绍和讲次目录，再按学习顺序查看资料与笔记。同一门课的不同年份分别保留各自的讲义、录像和作业版本。

需要查找某份讲义、代码、论文或教材时，可以进入[资料库](/generated/resources/)，检索关键词，或按课程和资料类型筛选。资料会保留对应讲次的入口，便于回到课程中继续学习。Lab 与作业单独收录课程官网公布的入口；有官方 GitHub 仓库时直接链接仓库，其他保留官方题目页及访问说明。

## 内容说明

- **课程笔记**：梳理一讲的概念、推导与学习重点。
- **Blog 解读**：围绕主题展开的独立解释。
- **中英文逐字稿**：带时间戳的讲述记录，便于回听和核对。
- **PDF**：部分课程笔记提供的阅读与打印版本。

各门课程的整理进度不同。官方资料、候选稿和已审核的正文分别标注；存在本地草稿不代表已发布。缺少真实字幕或录像时，不用摘要代替逐字稿。

## 来源与审核

讲义、视频、论文和代码保留原作者与课程方的来源链接。历史录像及补充资料标明版本，访问权限以原站为准。

AI 可以协助整理候选稿，候选稿经校验和人工审核后才进入正式内容。学习笔记仍可能存在疏漏，术语、公式和引用应结合原始资料核对。

## 维护与反馈

课程资料和笔记随学习进度持续更新。发现错误或失效链接时，可通过站点右上角的 GitHub 入口反馈，并注明课程、讲次及具体位置。

资源同步、候选稿生成、审核和网站构建的操作说明见[维护文档](/workflow/)。
