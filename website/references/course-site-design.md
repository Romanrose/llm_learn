# 优秀大学课程网站参考

这份清单关注的不是视觉炫技，而是一个课程站能否让学习者快速找到：课程说明、视频、讲义、作业、代码、逐讲内容与历史版本。它也作为 `llm_learn` 后续改版的长期参考。

## 可复用的发布模式

### 1. 课程首页负责建立全局路径

首页只回答四个问题：这是什么课、适合谁、按什么顺序学、每讲有哪些资源。课程日程应该成为唯一主索引，避免资源散落在多个导航层级。

### 2. 单讲页就是学习工作台

每讲保持固定顺序：页内视频 → 课程事实 → 课程简介 → 课程笔记 → Blog 解读 → 中文逐字稿 → 英文逐字稿。视频不应默认跳走，外部原页只作为播放器故障时的兜底。

### 3. 资源按教学语义展示

资源名旁边明确标出“讲义、代码、Slides、作业、阅读”，比一组外观相同的大卡片更容易扫描。日期、讲师、状态等稳定信息使用标签—值结构，不占用过多纵向空间。

### 4. 原始资料与学习产物分层

官方视频、讲义和作业属于“课程资料”；课程笔记、解读和双语逐字稿属于“学习产物”。两者保留来源关系，但不要混在一个列表里。

### 5. 保留历史版本和生成依据

课程会持续更新。元数据、原始字幕、生成稿、审核状态和最终发布页应当可追溯；课程站只展示通过审核的版本，仓库保留生成链路。

## 应用于 llm_learn

当前采用以下约定：

1. 顶部是可直接播放的课程视频，左侧只放本讲关键事实。
2. 视频下方固定提供五个页内入口，不再要求通过下拉导航进入内容。
3. 课程简介使用紧凑的标签—值表；官方资料使用单行资源列表。
4. 每个课程继续由元数据生成，后续新增清华、北大、南大、上交等课程时共用同一发布模板。
5. 本页作为设计基线；每次重构先说明借鉴对象与要解决的问题，再调整组件。
